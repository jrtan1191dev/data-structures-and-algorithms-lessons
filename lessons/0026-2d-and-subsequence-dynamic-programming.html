2D & Subsequence Dynamic Programming

State transition grids for string alignments and knapsack variants, row-by-row rolling buffers, and backward array traversals for $O(N)$ space compression.

1. Memory & Architecture

2D State Grids in Virtual Memory

Multi-dimensional dynamic programming models problems with two independent state variables, such as indices into two strings $(i, j)$ or an item index and remaining weight capacity $(i, w)$.

Allocating a full 2D matrix dp[M+1][N+1] consumes $O(M \times N)$ contiguous memory. In systems programming, allocating large matrices causes CPU cache line pollution:

LCS Recurrence Relation
State: dp[i][j] = length of LCS between text1[0...i-1] and text2[0...j-1]

Transitions:
If text1[i-1] == text2[j-1]:
    dp[i][j] = dp[i-1][j-1] + 1       // Diagonal predecessor match
Else:
    dp[i][j] = max(dp[i-1][j], dp[i][j-1])  // Skip one character from either string

Compressing 2D Tables to 1D via Rolling Arrays

Notice that computing row $i$ relies only on row $i-1$. Cells from row $i-2$ and earlier are never read again!

  • Two-Row Rolling Buffer: Maintain prev_row and curr_row of size $N+1$, swapping pointers after each outer iteration ($O(N)$ space).
  • 0/1 Knapsack Reverse Traversal: In Partition Equal Subset Sum (LC 416), traversing the single 1D array backwards from target down to num guarantees that each element is used at most once, preventing an item from contributing to its own state transitions within the same pass.

3. Trilingual Reference Implementations

LC 1143: Longest Common Subsequence ($O(M \cdot N)$ Time, $O(N)$ Space)

Python 3: 1D Rolling Row Buffer
def longestCommonSubsequence(text1: str, text2: str) -> int:
    # Ensure text2 is the shorter string to minimize O(N) memory
    if len(text1) < len(text2):
        text1, text2 = text2, text1

    m, n = len(text1), len(text2)
    prev = [0] * (n + 1)
    curr = [0] * (n + 1)

    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if text1[i - 1] == text2[j - 1]:
                curr[j] = prev[j - 1] + 1
            else:
                curr[j] = max(prev[j], curr[j - 1])
        prev, curr = curr, [0] * (n + 1)

    return prev[n]
TypeScript: Dual Typed Array Space Optimization
function longestCommonSubsequence(text1: string, text2: string): number {
  if (text1.length < text2.length) {
    const temp = text1;
    text1 = text2;
    text2 = temp;
  }

  const m = text1.length;
  const n = text2.length;
  let prev = new Int32Array(n + 1);
  let curr = new Int32Array(n + 1);

  for (let i = 1; i <= m; i++) {
    for (let j = 1; j <= n; j++) {
      if (text1[i - 1] === text2[j - 1]) {
        curr[j] = prev[j - 1] + 1;
      } else {
        curr[j] = Math.max(prev[j], curr[j - 1]);
      }
    }
    prev.set(curr);
    curr.fill(0);
  }

  return prev[n];
}
Java 21: Rolling Primitive Arrays
public class Solution {
    public int longestCommonSubsequence(String text1, String text2) {
        if (text1.length() < text2.length()) {
            String temp = text1;
            text1 = text2;
            text2 = temp;
        }

        int m = text1.length();
        int n = text2.length();
        int[] prev = new int[n + 1];
        int[] curr = new int[n + 1];

        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (text1.charAt(i - 1) == text2.charAt(j - 1)) {
                    curr[j] = prev[j - 1] + 1;
                } else {
                    curr[j] = Math.max(prev[j], curr[j - 1]);
                }
            }
            System.arraycopy(curr, 0, prev, 0, n + 1);
            java.util.Arrays.fill(curr, 0);
        }

        return prev[n];
    }
}
