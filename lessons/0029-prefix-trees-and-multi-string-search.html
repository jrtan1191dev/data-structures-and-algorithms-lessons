Prefix Trees (Tries) & Multi-String Search

26-ary tree node pointers in heap memory, O(L) prefix querying independent of dictionary size, wildcard backtracks, and exponential grid pruning.

1. Memory & Architecture

The Trie Node in Memory

A Trie (pronounced "try" from retrieval) is an $M$-ary tree structure where each edge represents a character, and common string prefixes share common ancestor pathways:

Heap Memory Layout of a TrieNode (Lowercase English Alphabet)
class TrieNode {
    // Array of 26 pointers (each 8 bytes on 64-bit architecture = 208 bytes)
    TrieNode* children[26];
    
    // 1-byte boolean flag marking whether a word terminates at this node
    bool is_end_of_word;
}
Trie vs Hash Table for Prefix Operations: While a hash table checks exact word membership in $O(L)$ time, finding whether any word starts with prefix "app" requires scanning through all $N$ dictionary keys ($O(N \cdot L)$). A Trie executes both exact lookup and prefix searches in strictly O(L) steps, completely independent of the total number of words $N$ stored!

Exponential Grid Pruning (LC 212 Word Search II)

Searching for $W$ separate words in an $R \times C$ character grid naively requires running $W$ independent DFS passes: $O(W \cdot R \cdot C \cdot 4^L)$.

By loading all words into a single Trie and traversing the grid alongside the Trie nodes, we can abort grid exploration the instant the current cell's character does not exist as a child in the Trie. This prunes billions of dead branches and completes the search in a single pass.

Python 3: Dict-Backed Trie Node
class TrieNode:
    def __init__(self):
        self.children = {}
        self.is_end = False

class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word: str) -> None:
        curr = self.root
        for ch in word:
            if ch not in curr.children:
                curr.children[ch] = TrieNode()
            curr = curr.children[ch]
        curr.is_end = True

    def search(self, word: str) -> bool:
        curr = self.root
        for ch in word:
            if ch not in curr.children:
                return False
            curr = curr.children[ch]
        return curr.is_end

    def startsWith(self, prefix: str) -> bool:
        curr = self.root
        for ch in prefix:
            if ch not in curr.children:
                return False
            curr = curr.children[ch]
        return True
TypeScript: Fixed 26-Pointer Array Node
class TrieNode {
  children: Array = new Array(26).fill(null);
  isEnd = false;
}

class Trie {
  private root = new TrieNode();

  insert(word: string): void {
    let curr = this.root;
    for (let i = 0; i < word.length; i++) {
      const idx = word.charCodeAt(i) - 97;
      if (curr.children[idx] === null) {
        curr.children[idx] = new TrieNode();
      }
      curr = curr.children[idx]!;
    }
    curr.isEnd = true;
  }

  search(word: string): boolean {
    let curr = this.root;
    for (let i = 0; i < word.length; i++) {
      const idx = word.charCodeAt(i) - 97;
      if (curr.children[idx] === null) return false;
      curr = curr.children[idx]!;
    }
    return curr.isEnd;
  }

  startsWith(prefix: string): boolean {
    let curr = this.root;
    for (let i = 0; i < prefix.length; i++) {
      const idx = prefix.charCodeAt(i) - 97;
      if (curr.children[idx] === null) return false;
      curr = curr.children[idx]!;
    }
    return true;
  }
}
Java 21: Fast Array-Pointer Trie
public class Trie {
    private static class TrieNode {
        TrieNode[] children = new TrieNode[26];
        boolean isEnd = false;
    }

    private final TrieNode root;

    public Trie() {
        this.root = new TrieNode();
    }

    public void insert(String word) {
        TrieNode curr = root;
        for (int i = 0; i < word.length(); i++) {
            int idx = word.charAt(i) - 'a';
            if (curr.children[idx] == null) {
                curr.children[idx] = new TrieNode();
            }
            curr = curr.children[idx];
        }
        curr.isEnd = true;
    }

    public boolean search(String word) {
        TrieNode curr = root;
        for (int i = 0; i < word.length(); i++) {
            int idx = word.charAt(i) - 'a';
            if (curr.children[idx] == null) return false;
            curr = curr.children[idx];
        }
        return curr.isEnd;
    }

    public boolean startsWith(String prefix) {
        TrieNode curr = root;
        for (int i = 0; i < prefix.length(); i++) {
            int idx = prefix.charAt(i) - 'a';
            if (curr.children[idx] == null) return false;
            curr = curr.children[idx];
        }
        return true;
    }
}
