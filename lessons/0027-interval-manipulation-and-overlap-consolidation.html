Sorting invariants for temporal sequences, greedy boundary extension, non-overlapping elimination, and conference room allocation.

1. Memory & Architecture

The Sorting Precondition for Continuous Intervals

Intervals model continuous spans across a 1-dimensional coordinate space $[start, end]$. When intervals arrive in arbitrary order, detecting collisions or overlaps requires comparing every interval against every other interval ($O(N^2)$ comparisons).

By sorting intervals upfront by their start coordinate ($O(N \log N)$), we establish a strict monotonic invariant: for any two adjacent intervals $A$ and $B$, $A.start \le B.start$.

The 3 Mutual Relationship States Between Ordered Intervals
Case 1: Disjoint / Non-overlapping
[ A.start ----------- A.end ]
                                [ B.start ----------- B.end ]
Condition: B.start > A.end  -> Append A, start tracking B.

Case 2: Partial Overlap
[ A.start ----------- A.end ]
             [ B.start ----------- B.end ]
Condition: B.start <= A.end and B.end > A.end  -> Extend A.end = B.end.

Case 3: Total Subsumption / Absorption
[ A.start ----------------------------------- A.end ]
             [ B.start ----------- B.end ]
Condition: B.start <= A.end and B.end <= A.end -> A.end remains unchanged.
Greedy Interval Scheduling Principle: When selecting the maximum number of mutually compatible non-overlapping intervals (LC 435), always sort by end time ascendingly. Picking the interval that finishes earliest frees up the remaining timeline for the maximum number of future events.

3. Trilingual Reference Implementations

LC 56: Merge Intervals ($O(N \log N)$ Time, $O(N)$ Space)

Python 3: Sort by Start Time & Greedy Extend
from typing import List

def merge(intervals: List[List[int]]) -> List[List[int]]:
    if not intervals:
        return []

    # Sort ascendingly by start coordinate
    intervals.sort(key=lambda x: x[0])
    merged = [intervals[0]]

    for curr in intervals[1:]:
        prev_start, prev_end = merged[-1]
        curr_start, curr_end = curr

        if curr_start <= prev_end:
            # Overlapping: extend previous boundary
            merged[-1][1] = max(prev_end, curr_end)
        else:
            # Disjoint: append new interval
            merged.append(curr)

    return merged
TypeScript: In-Place Sort & Array Consolidation
function merge(intervals: number[][]): number[][] {
  if (intervals.length === 0) return [];

  // Sort ascendingly by start coordinate
  intervals.sort((a, b) => a[0] - b[0]);
  const merged: number[][] = [intervals[0]];

  for (let i = 1; i < intervals.length; i++) {
    const prev = merged[merged.length - 1];
    const curr = intervals[i];

    if (curr[0] <= prev[1]) {
      // Overlapping: extend end coordinate
      prev[1] = Math.max(prev[1], curr[1]);
    } else {
      // Disjoint: append new interval
      merged.push(curr);
    }
  }

  return merged;
}
Java 21: Comparator Sort & List Consolidation
import java.util.ArrayList;
import java.util.Arrays;
import java.util.Comparator;
import java.util.List;

public class Solution {
    public int[][] merge(int[][] intervals) {
        if (intervals == null || intervals.length == 0) return new int[0][0];

        // Sort ascendingly by start coordinate
        Arrays.sort(intervals, Comparator.comparingInt(a -> a[0]));
        List merged = new ArrayList<>();
        merged.add(intervals[0]);

        for (int i = 1; i < intervals.length; i++) {
            int[] prev = merged.get(merged.size() - 1);
            int[] curr = intervals[i];

            if (curr[0] <= prev[1]) {
                // Overlapping: extend end coordinate
                prev[1] = Math.max(prev[1], curr[1]);
            } else {
                // Disjoint: append new interval
                merged.add(curr);
            }
        }

        return merged.toArray(new int[merged.size()][]);
    }
}
