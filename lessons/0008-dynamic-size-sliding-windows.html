Dynamic-Size Sliding Windows

Expand greedily on the right, contract lazily on the left. The universal template for finding optimal variable-length contiguous subarrays in strictly O(n) amortized time.

Unlike fixed windows where the span is constant, dynamic sliding windows grow and shrink elastically. They solve questions of the form: "Find the longest/shortest contiguous subarray that satisfies property P."

💡

Tied to Your Interview Mission

Candidates often worry that the inner while loop makes dynamic sliding windows $O(n^2)$. Amortized Proof: The right pointer advances from $0$ to $n - 1$ ($n$ steps). The left pointer also moves strictly from $0$ to $n - 1$ ($n$ steps). Because neither pointer ever moves backward, the total number of pointer moves across the entire execution is at most $2n$ → strictly O(n) linear runtime.

1. The Expand-and-Contract Mental Model

Think of the sliding window as a rubber band or caterpillar:

  1. Expand (Head): Move the right pointer forward, incorporating the new element into our window state (frequency map, sum, etc.).
  2. Evaluate: Check if our window invariant is broken (or satisfied, if searching for a minimum window).
  3. Contract (Tail): While the condition requires it, move the left pointer forward, removing outgoing elements from our state until the window becomes valid again.
  4. Update Result: Record the maximum or minimum window length: length = right - left + 1.

2. Grind 75 Questions & Key Learning Points

LeetCode 121 • Easy Grind 75 Week 1
Best Time to Buy and Sell Stock

Key Learning Point: The simplest 1-sided dynamic sliding window. Maintain left as the minimum price observed. Move right forward. If prices[right] < prices[left], a new minimum has been found → snap left = right. Otherwise, compute profit = prices[right] - prices[left].

LeetCode 3 • Medium Grind 75 Week 2
Longest Substring Without Repeating Characters

Key Learning Point: Store each character's most recent index in a hash map. When a duplicate character is encountered at index right, if its last seen index is $\ge left$, jump left = last_seen[char] + 1 in $O(1)$ instead of incrementing left one step at a time!

LeetCode 424 • Medium Grind 75 Week 6
Longest Repeating Character Replacement

Key Learning Point: A window is valid if (window_len - max_frequency) ≤ k (we can replace all other characters with the majority character). If invalid, slide left += 1.

LeetCode 76 • Hard Grind 75 Week 8
Minimum Window Substring

Key Learning Point: Track have vs need unique character frequency matches. Expand right until have == need. Then greedily shrink left while maintaining have == need to find the shortest valid substring.

3. The Universal Sliding Window Template

def sliding_window_template(sequence):
    left = 0
    state = initialize_state()
    best_result = 0

    for right in range(len(sequence)):
        # 1. Add right element to window state
        add_to_state(sequence[right])

        # 2. While window condition is violated (or valid for min-window)
        while is_invalid():
            remove_from_state(sequence[left])
            left += 1

        # 3. Update answer with current window
        best_result = max(best_result, right - left + 1)

    return best_result

4. Multi-Language Implementations: Longest Substring Without Repeating

Solving LeetCode 3 (Grind 75) in $O(n)$ time and $O(\min(n, m))$ space across Python, TypeScript, and Java: 

def length_of_longest_substring(s: str) -> int:
    """
    LeetCode 3 (Grind 75) - Dynamic Window with Index Jump.
    Time Complexity:  O(n) - right advances n times, left jumps forward.
    Space Complexity: O(min(n, alphabet)) - hash map of character indices.
    """
    last_seen = {}
    left = 0
    max_len = 0

    for right, ch in enumerate(s):
        # If character is already in window, jump left past duplicate
        if ch in last_seen and last_seen[ch] >= left:
            left = last_seen[ch] + 1

        last_seen[ch] = right
        max_len = max(max_len, right - left + 1)

    return max_len
function lengthOfLongestSubstring(s: string): number {
    // Time Complexity:  O(n) single pass
    // Space Complexity: O(min(n, alphabet))
    const lastSeen = new Map();
    let left = 0;
    let maxLen = 0;

    for (let right = 0; right < s.length; right++) {
        const ch = s[right];
        if (lastSeen.has(ch)) {
            const prevIdx = lastSeen.get(ch)!;
            if (prevIdx >= left) {
                left = prevIdx + 1; // Direct O(1) jump
            }
        }

        lastSeen.set(ch, right);
        maxLen = Math.max(maxLen, right - left + 1);
    }

    return maxLen;
}
import java.util.HashMap;

public class LongestSubstring {
    /**
     * LeetCode 3 (Grind 75) in O(n) time and O(min(n, alphabet)) space.
     */
    public static int lengthOfLongestSubstring(String s) {
        HashMap<Character, Integer> lastSeen = new HashMap<>();
        int left = 0;
        int maxLen = 0;

        for (int right = 0; right < s.length(); right++) {
            char ch = s.charAt(right);
            if (lastSeen.containsKey(ch)) {
                int prevIdx = lastSeen.get(ch);
                if (prevIdx >= left) {
                    left = prevIdx + 1;
                }
            }

            lastSeen.put(ch, right);
            maxLen = Math.max(maxLen, right - left + 1);
        }

        return maxLen;
    }
}
