Binary Heap Mechanics & Heapify

Compact array representation of complete binary trees, cache locality benefits, Floyd's O(n) heapify proof, and multiway list consolidation.

1. Memory & Architecture

Complete Binary Trees in Flat Memory

A complete binary tree has every level filled except possibly the last, which is filled from left to right. Because there are no interior gaps, a complete tree can be mapped directly into a contiguous dynamic array without storing any pointers:

  • Root index: 0
  • Left child of index i: 2*i + 1
  • Right child of index i: 2*i + 2
  • Parent of index i: floor((i - 1) / 2)
Hardware Locality Advantage: Unlike a pointer-based binary search tree where traversing from parent to child requires dereferencing an arbitrary heap address (causing L1/L2 cache misses), an array-based binary heap resides in contiguous virtual memory pages. Sequential scans and upward/downward sift steps operate on contiguous cache lines.

Why Floyd's build_heap is O(n), not O(n log n)

Inserting $n$ items one by one into an initially empty heap performs $n$ sift-up steps, costing $O(n \log n)$. In contrast, Floyd's bottom-up heapify operates by sifting down from the lowest non-leaf node (index $\lfloor n/2 \rfloor - 1$) down to the root:

Mathematical Work Bound
Height h=0: ~ n/2 nodes,    work = 0 steps
Height h=1: ~ n/4 nodes,    work = 1 step
Height h=2: ~ n/8 nodes,    work = 2 steps
...
Total Work S = Sum_{h=0}^{log n} (n / 2^(h+1)) * h = n * Sum_{h=0}^{log n} (h / 2^(h+1))

Since the infinite series Sum_{h=1}^inf (h / 2^h) converges to 2:
Total Operations <= 2 * n = O(n)

Python 3: heapq with Unique Counter Disambiguation
import heapq
from typing import List, Optional

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

def mergeKLists(lists: List[Optional[ListNode]]) -> Optional[ListNode]:
    dummy = ListNode(0)
    curr = dummy
    heap = []
    
    # Counter prevents comparing ListNode objects when vals are equal
    counter = 0
    for node in lists:
        if node:
            heapq.heappush(heap, (node.val, counter, node))
            counter += 1
            
    while heap:
        val, _, node = heapq.heappop(heap)
        curr.next = node
        curr = curr.next
        
        if node.next:
            heapq.heappush(heap, (node.next.val, counter, node.next))
            counter += 1
            
    return dummy.next
TypeScript: Array-Backed MinHeap Implementation
class ListNode {
  val: number;
  next: ListNode | null;
  constructor(val = 0, next: ListNode | null = null) {
    this.val = val;
    this.next = next;
  }
}

class MinHeap {
  private data: ListNode[] = [];

  push(node: ListNode): void {
    this.data.push(node);
    this.siftUp(this.data.length - 1);
  }

  pop(): ListNode | null {
    if (this.data.length === 0) return null;
    const top = this.data[0];
    const bottom = this.data.pop()!;
    if (this.data.length > 0) {
      this.data[0] = bottom;
      this.siftDown(0);
    }
    return top;
  }

  get size(): number { return this.data.length; }

  private siftUp(i: number): void {
    while (i > 0) {
      const p = Math.floor((i - 1) / 2);
      if (this.data[i].val < this.data[p].val) {
        [this.data[i], this.data[p]] = [this.data[p], this.data[i]];
        i = p;
      } else break;
    }
  }

  private siftDown(i: number): void {
    const n = this.data.length;
    while (2 * i + 1 < n) {
      let smallest = 2 * i + 1;
      const right = 2 * i + 2;
      if (right < n && this.data[right].val < this.data[smallest].val) {
        smallest = right;
      }
      if (this.data[smallest].val < this.data[i].val) {
        [this.data[i], this.data[smallest]] = [this.data[smallest], this.data[i]];
        i = smallest;
      } else break;
    }
  }
}

function mergeKLists(lists: Array): ListNode | null {
  const heap = new MinHeap();
  for (const node of lists) {
    if (node) heap.push(node);
  }

  const dummy = new ListNode(0);
  let curr = dummy;

  while (heap.size > 0) {
    const node = heap.pop()!;
    curr.next = node;
    curr = curr.next;
    if (node.next) heap.push(node.next);
  }

  return dummy.next;
}
Java 21: PriorityQueue with Comparator
import java.util.PriorityQueue;
import java.util.Comparator;

public class Solution {
    public static class ListNode {
        int val;
        ListNode next;
        ListNode(int val) { this.val = val; }
    }

    public ListNode mergeKLists(ListNode[] lists) {
        if (lists == null || lists.length == 0) return null;

        PriorityQueue minHeap = new PriorityQueue<>(
            lists.length,
            Comparator.comparingInt(a -> a.val)
        );

        for (ListNode node : lists) {
            if (node != null) {
                minHeap.offer(node);
            }
        }

        ListNode dummy = new ListNode(0);
        ListNode curr = dummy;

        while (!minHeap.isEmpty()) {
            ListNode smallest = minHeap.poll();
            curr.next = smallest;
            curr = curr.next;

            if (smallest.next != null) {
                minHeap.offer(smallest.next);
            }
        }

        return dummy.next;
    }
}
