Fast & Slow Pointers (Floyd's Cycle)

How two pointers traversing at 1x and 2x velocities detect cycles, find midpoints, and locate duplicates in O(n) time with strictly O(1) space.

While converging pointers move in opposite directions on sorted sequences, Fast & Slow Pointers (also known as Floyd's Tortoise and Hare algorithm) move in the same direction at different velocities.

💡

Tied to Your Interview Mission

The naive way to detect cycles or find duplicates uses a hash set of visited nodes, costing O(n) auxiliary memory. Interviewers at FAANG tier specifically forbid extra memory to test whether you can apply Floyd's algorithm to achieve O(1) space.

1. The Velocity Differential Principle

We initialize two pointers at the starting node:

  • slow moves 1 step per iteration: slow = slow.next
  • fast moves 2 steps per iteration: fast = fast.next.next

Scenario A (Acyclic Sequence): If there is no cycle, fast (or fast.next) will hit null / the end of the list. We can safely conclude there is no loop in O(n) time. Furthermore, at the moment fast reaches the end, slow is positioned precisely at the middle node.

Scenario B (Cyclic Sequence): If a cycle exists, fast enters the loop first, followed by slow. Once both are inside the circular loop, the distance between them closes by exactly 1 step on every iteration. They are mathematically guaranteed to collide.

2. Mathematical Proof of Cycle Convergence

Suppose the cycle has length C. Once both pointers are in the cycle, let the distance from slow forward to fast be D: 

On each tick:
Distance traveled by slow: +1
Distance traveled by fast: +2
Relative gain by fast:     +1 step per tick

Gap closing: (D - 1) mod C, (D - 2) mod C, ... -> 0

Because the gap decreases by 1 integer every step, fast cannot "jump over" slow. They must meet within at most C steps after slow enters the cycle.

3. Locating the Cycle Entrance: Phase 2

Detecting that a cycle exists is only Phase 1. Finding the exact entry node of the cycle requires an elegant mathematical identity: 

Let:
L = distance from head to cycle entrance
K = distance from cycle entrance to meeting point
C = total length of the cycle

Distance(slow) = L + K
Distance(fast) = 2 * Distance(slow) = 2(L + K)

Also, fast traveled an extra m full loops:
Distance(fast) = L + K + m * C

Equating both expressions:
2(L + K) = L + K + m * C
L + K = m * C
L = m * C - K = (m - 1) * C + (C - K)

Notice what (C - K) represents: it is the distance from the meeting point to the cycle entrance!

The Algorithm: Keep slow at the meeting point. Move another pointer p = head. Advance both p and slow at 1 step per tick. After exactly L steps, they collide at the entrance node!

4. Multi-Language Implementations: Find the Duplicate Number

In LeetCode 287 (Find the Duplicate Number), we are given an array of $n + 1$ integers in the range $[1, n]$. By treating each array index as a node pointing to nums[i], the duplicate number acts as the entrance to a cycle: 

def find_duplicate(nums: list[int]) -> int:
    """
    Finds the duplicate in O(n) time and strictly O(1) space
    without modifying the input array.
    """
    # Phase 1: Detect intersection within the cycle
    slow = nums[0]
    fast = nums[0]

    while True:
        slow = nums[slow]           # 1 step
        fast = nums[nums[fast]]     # 2 steps
        if slow == fast:
            break

    # Phase 2: Locate the entrance to the cycle
    ptr1 = nums[0]
    ptr2 = slow
    while ptr1 != ptr2:
        ptr1 = nums[ptr1]           # 1 step
        ptr2 = nums[ptr2]           # 1 step

    return ptr1
function findDuplicate(nums: number[]): number {
    // Time Complexity:  O(n)
    // Space Complexity: O(1)
    let slow = nums[0];
    let fast = nums[0];

    // Phase 1: Find meeting point in cycle
    do {
        slow = nums[slow];
        fast = nums[nums[fast]];
    } while (slow !== fast);

    // Phase 2: Find entrance of cycle
    let ptr1 = nums[0];
    let ptr2 = slow;
    while (ptr1 !== ptr2) {
        ptr1 = nums[ptr1];
        ptr2 = nums[ptr2];
    }

    return ptr1;
}
public class FloydCycle {
    /**
     * Finds the duplicate number in O(n) time and O(1) space.
     */
    public static int findDuplicate(int[] nums) {
        int slow = nums[0];
        int fast = nums[0];

        // Phase 1: Locate meeting point
        do {
            slow = nums[slow];
            fast = nums[nums[fast]];
        } while (slow != fast);

        // Phase 2: Locate cycle entrance
        int ptr1 = nums[0];
        int ptr2 = slow;
        while (ptr1 != ptr2) {
            ptr1 = nums[ptr1];
            ptr2 = nums[ptr2];
        }

        return ptr1;
    }
}
