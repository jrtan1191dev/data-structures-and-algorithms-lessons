Bitwise Arithmetic & Binary Masking

CPU ALU bitwise operations, XOR self-cancellation identities, Brian Kernighan's bit-clearing mask, and O(N) bit-count dynamic programming.

1. Memory & Architecture

Hardware ALU Registers & Bitwise Primitives

At the physical transistor level, integer variables reside in fixed-width CPU hardware registers (typically 32-bit or 64-bit words). Bitwise instructions execute in a single CPU cycle on the Arithmetic Logic Unit (ALU):

Universal Bitwise Identities
1. XOR Self-Cancellation:
   x ^ x = 0
   x ^ 0 = x
   Property: Commutative and associative. Order of operations does not matter!

2. Brian Kernighan's Lowest Set Bit Clearing:
   n & (n - 1)
   Subtracting 1 flips all bits from the rightmost set bit downward.
   ANDing with original n clears the lowest set bit to 0 in a single cycle.

3. Extract Lowest Set Bit:
   lowest_bit = n & (-n)
   Due to two's complement arithmetic: -n = (~n) + 1.
Language Bitwise Nuances: In JavaScript/TypeScript, all numbers are 64-bit floating point by default. However, applying any bitwise operator (&, |, ^, >>) truncates the operand to a 32-bit signed integer. In Java, >> is arithmetic right shift (preserves sign bit), while >>> is logical unsigned right shift (fills with zeroes).

Target Grind 75 Questions & Architectural Takeaways

Problem Difficulty Core Pattern Intended Lesson & Mental Takeaway
LC 136: Single Number Easy XOR Accumulator XOR all elements together. Identical pairs cancel out to 0 ($x \oplus x = 0$), leaving the unique element in $O(N)$ time and $O(1)$ space.
LC 191: Number of 1 Bits Easy Brian Kernighan's Mask Iterate n = n & (n - 1) until n == 0. Loop iterations equal the exact number of set bits (Hamming weight).

LC 268: Missing Number Easy XOR Range Invariance XOR all indices $0 \dots N$ with all array values. Complete pairs cancel to zero, leaving only the missing number without integer overflow.
LC 190: Reverse Bits Easy Bit Shift Accumulator Loop 32 times: shift result left by 1 and OR with the least significant bit of n, then shift n right by 1.
3. Trilingual Reference Implementations

LC 338: Counting Bits ($O(N)$ Time, $O(N)$ Space Linear DP)

Python 3: Right Shift Subproblem DP
from typing import List

def countBits(n: int) -> List[int]:
    dp = [0] * (n + 1)
    for i in range(1, n + 1):
        # i >> 1 is i // 2; (i & 1) is 1 if odd, 0 if even
        dp[i] = dp[i >> 1] + (i & 1)
    return dp
TypeScript: Fast Typed Int32Array Bit DP
function countBits(n: number): number[] {
  const dp = new Int32Array(n + 1);
  for (let i = 1; i <= n; i++) {
    dp[i] = dp[i >> 1] + (i & 1);
  }
  return Array.from(dp);
}
Java 21: Primitive int[] Bit DP
public class Solution {
    public int[] countBits(int n) {
        int[] dp = new int[n + 1];
        for (int i = 1; i <= n; i++) {
            dp[i] = dp[i >> 1] + (i & 1);
        }
        return dp;
    }
}
