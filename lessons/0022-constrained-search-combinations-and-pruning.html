Constrained Search: Combinations & Pruning

Branch-and-bound pruning, duplicate elimination via sorting, and in-place matrix mutation rollback for zero-allocation grid search.

1. Memory & Architecture

Pruning the Exponential Growth

Unchecked backtracking generates combinatorial explosion ($O(2^N)$ or $O(K^N)$). Pruning aborts unproductive search branches as soon as mathematical constraints are breached, preventing the traversal of vast dead subtrees:

  • Sorted Pruning (LC 39 Combination Sum): When candidates are sorted ascendingly, if candidates[i] > remaining_target, every subsequent candidate $j > i$ will also exceed the target. We can immediately break the branch loop rather than merely continue.
  • In-Place Grid State Mutation (LC 79 Word Search): Maintaining a 2D boolean visited[][] matrix requires allocating a new memory table and paying continuous cache-miss penalties. Instead, temporarily overwrite the grid cell in RAM with a sentinel (e.g. board[r][c] = '#'), explore adjacent neighbors, and restore the original character upon return. This achieves $O(1)$ auxiliary memory!
Zero-Allocation In-Place Rollback Pattern
// Mark visited by overwriting memory cell
char original = board[r][c];
board[r][c] = '#';

// Explore 4 cardinal directions
boolean found = dfs(r + 1, c, k + 1) || dfs(r - 1, c, k + 1) ||
                dfs(r, c + 1, k + 1) || dfs(r, c - 1, k + 1);

// Rollback / Un-choose: restore original byte
board[r][c] = original;
return found;

3. Trilingual Reference Implementations

LC 79: Word Search (In-Place Memory Mutation & Rollback)

Python 3: In-Place Board Mutation DFS
from typing import List

def exist(board: List[List[str]], word: str) -> bool:
    rows, cols = len(board), len(board[0])

    def dfs(r: int, c: int, idx: int) -> bool:
        if idx == len(word):
            return True
        if r < 0 or r >= rows or c < 0 or c >= cols or board[r][c] != word[idx]:
            return False

        # In-place mark visited
        temp = board[r][c]
        board[r][c] = "#"

        # Explore 4 orthogonal neighbors
        found = (dfs(r + 1, c, idx + 1) or
                 dfs(r - 1, c, idx + 1) or
                 dfs(r, c + 1, idx + 1) or
                 dfs(r, c - 1, idx + 1))

        # Rollback state
        board[r][c] = temp
        return found

    for r in range(rows):
        for c in range(cols):
            if board[r][c] == word[0] and dfs(r, c, 0):
                return True
    return False
TypeScript: In-Place Char Rollback DFS
function exist(board: string[][], word: string): boolean {
  const rows = board.length;
  const cols = board[0].length;

  function dfs(r: number, c: number, idx: number): boolean {
    if (idx === word.length) return true;
    if (r < 0 || r >= rows || c < 0 || c >= cols || board[r][c] !== word[idx]) {
      return false;
    }

    const temp = board[r][c];
    board[r][c] = "#";

    const found =
      dfs(r + 1, c, idx + 1) ||
      dfs(r - 1, c, idx + 1) ||
      dfs(r, c + 1, idx + 1) ||
      dfs(r, c - 1, idx + 1);

    board[r][c] = temp; // Rollback
    return found;
  }

  for (let r = 0; r < rows; r++) {
    for (let c = 0; c < cols; c++) {
      if (board[r][c] === word[0] && dfs(r, c, 0)) {
        return true;
      }
    }
  }
  return false;
}
Java 21: Primitive char[][] In-Place Rollback
public class Solution {
    public boolean exist(char[][] board, String word) {
        int rows = board.length;
        int cols = board[0].length;

        for (int r = 0; r < rows; r++) {
            for (int c = 0; c < cols; c++) {
                if (board[r][c] == word.charAt(0) && dfs(board, word, r, c, 0)) {
                    return true;
                }
            }
        }
        return false;
    }

    private boolean dfs(char[][] board, String word, int r, int c, int idx) {
        if (idx == word.length()) return true;
        if (r < 0 || r >= board.length || c < 0 || c >= board[0].length || board[r][c] != word.charAt(idx)) {
            return false;
        }

        char temp = board[r][c];
        board[r][c] = '#'; // Mark visited

        boolean found = dfs(board, word, r + 1, c, idx + 1) ||
                        dfs(board, word, r - 1, c, idx + 1) ||
                        dfs(board, word, r, c + 1, idx + 1) ||
                        dfs(board, word, r, c - 1, idx + 1);

        board[r][c] = temp; // Rollback
        return found;
    }
}
