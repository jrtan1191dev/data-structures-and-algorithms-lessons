Binary Search on Answer Space

Moving beyond array indices. Using monotonic boolean predicate functions f(x) → {True, False} to find minimum feasible speeds, capacities, and costs in O(n log M) time.

In advanced technical interviews, binary search is rarely used just to find an integer in an array. Instead, it is used to solve optimization problems: "Find the minimum capacity to finish within D days", or "Find the slowest speed to finish before the deadline."

💡

Tied to Your Interview Mission

The signal to trigger this pattern is phrasing like: "Minimize the maximum" or "Find the minimum X such that condition Y holds." If a candidate solution $k$ makes the condition true, and all values $k' > k$ also make it true, you have a monotonic predicate ready for binary search!

1. The Monotonic Predicate Mental Model

Instead of searching an input array, our search space is the domain of possible answers: $[low, high]$. We write a helper function (the predicate): 

can_finish(speed) -> bool:
   Returns True if Koko can finish all piles within h hours at this speed.

Notice how this function behaves across candidate speeds: 

Speed:       1       2       3       4       5       6       7 ...
Feasible: [False,  False,  False,  True,   True,   True,   True]
                                     ^
                             We want the FIRST True!

Because the sequence of boolean answers is monotonic, we can binary search over the integer range $[1, \max(\text{piles})]$ in O(log(max_speed)) steps!

2. Grind 75 Questions & Key Learning Points

LeetCode 875 • Medium Grind 75 Week 5
Koko Eating Bananas

Key Learning Point: Define search bounds left = 1, right = max(piles). In the predicate, total hours spent is $\sum \lceil p / k \rceil$. If hours $\le h$, this speed is feasible → search lower speeds (`right = mid`). Otherwise, speed is too slow → search higher speeds (`left = mid + 1`).

LeetCode 981 • Medium Grind 75 Week 5
Time Based Key-Value Store

Key Learning Point: Map key -> list_of_(timestamp, value). Timestamps are strictly increasing by problem definition. Use binary search (right-boundary / upper bound) to find the largest timestamp $\le target$ in $O(\log n)$ time.

3. Canonical Problem: Koko Eating Bananas

To avoid floating-point math when computing ceiling division $\lceil p / k \rceil$, use integer arithmetic: 

hours_for_pile = (pile + k - 1) // k

4. Multi-Language Implementations

Solving LeetCode 875 (Grind 75) in $O(n \log M)$ time and $O(1)$ space across Python, TypeScript, and Java: 

import math

def min_eating_speed(piles: list[int], h: int) -> int:
    """
    LeetCode 875 (Grind 75) - Binary Search on Answer Space.
    Time Complexity:  O(n * log(max(piles)))
    Space Complexity: O(1)
    """
    left = 1
    right = max(piles)
    ans = right

    def can_finish(k: int) -> bool:
        total_hours = sum(math.ceil(p / k) for p in piles)
        return total_hours <= h

    while left <= right:
        mid = left + (right - left) // 2

        if can_finish(mid):
            ans = mid          # Feasible; try to find an even smaller speed
            right = mid - 1
        else:
            left = mid + 1     # Too slow; must increase speed

    return ans
function minEatingSpeed(piles: number[], h: number): number {
    let left = 1;
    let right = Math.max(...piles);
    let ans = right;

    function canFinish(k: number): boolean {
        let totalHours = 0;
        for (const p of piles) {
            totalHours += Math.ceil(p / k);
            if (totalHours > h) return false; // Early exit
        }
        return totalHours <= h;
    }

    while (left <= right) {
        const mid = left + Math.floor((right - left) / 2);

        if (canFinish(mid)) {
            ans = mid;
            right = mid - 1;
        } else {
            left = mid + 1;
        }
    }

    return ans;
}
public class KokoEating {
    /**
     * LeetCode 875 (Grind 75) in O(n log M) time and O(1) space.
     */
    public static int minEatingSpeed(int[] piles, int h) {
        int left = 1;
        int right = 1;
        for (int p : piles) {
            right = Math.max(right, p);
        }
        int ans = right;

        while (left <= right) {
            int mid = left + (right - left) / 2;

            if (canFinish(piles, h, mid)) {
                ans = mid;
                right = mid - 1;
            } else {
                left = mid + 1;
            }
        }

        return ans;
    }

    private static boolean canFinish(int[] piles, int h, int k) {
        long totalHours = 0;
        for (int p : piles) {
            totalHours += (p + k - 1) / k; // Safe integer ceil division
            if (totalHours > h) return false;
        }
        return totalHours <= h;
    }
}
