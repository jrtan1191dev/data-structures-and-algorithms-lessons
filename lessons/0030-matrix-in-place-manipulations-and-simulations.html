Matrix In-Place Manipulations & Simulations

Row-major hardware stride effects, 4-boundary inward coordinate contraction, in-place matrix transposition, and row/column zero-marker compression.

1. Memory & Architecture

Row-Major Layout & Cache Line Strides

In systems memory, 2D arrays are stored sequentially in row-major order. Memory offset for coordinate $(r, c)$ in an $R \times C$ matrix is computed directly as:

Row-Major Memory Offset
Address(r, c) = BaseAddress + (r * C + c) * SizeOfElement

Scanning left-to-right across row $r$ streams through sequential memory addresses, exploiting hardware CPU cache prefetching. In contrast, scanning top-to-bottom down column $c$ jumps by $C \times \text{SizeOfElement}$ bytes each step, resulting in continuous cache misses on large matrices.

The 4-Boundary Inward Contraction Model (LC 54 Spiral Matrix)

To traverse a grid in a spiral without allocating visited tables, initialize four boundary coordinates: top = 0, bottom = R - 1, left = 0, right = C - 1.

  1. Traverse from left → right along top row. Increment top++.
  2. Traverse from top → bottom down right column. Decrement right--.
  3. If top ≤ bottom: traverse from right → left along bottom row. Decrement bottom--.
  4. If left ≤ right: traverse from bottom → top up left column. Increment left++.

In-Place 90° Rotation Without Auxiliary Memory (LC 48)

A 90° clockwise matrix rotation can be decomposed into two fundamental geometric transformations that operate entirely in-place:

Two-Step Geometric Decomposition
Step 1: Transpose Matrix (swap along main diagonal)
matrix[i][j] <-> matrix[j][i]  (for all i < j)

Step 2: Horizontally Reflect (reverse every row)
matrix[i][left] <-> matrix[i][right]  (converging two pointers per row)

Result: Perfect 90-degree clockwise rotation in O(N^2) time and O(1) auxiliary RAM!

Python 3: Inward Boundary Contraction
from typing import List

def spiralOrder(matrix: List[List[int]]) -> List[int]:
    if not matrix:
        return []

    top, bottom = 0, len(matrix) - 1
    left, right = 0, len(matrix[0]) - 1
    result = []

    while top <= bottom and left <= right:
        # 1. Traverse top row
        for c in range(left, right + 1):
            result.append(matrix[top][c])
        top += 1

        # 2. Traverse right column
        for r in range(top, bottom + 1):
            result.append(matrix[r][right])
        right -= 1

        # 3. Traverse bottom row (if valid)
        if top <= bottom:
            for c in range(right, left - 1, -1):
                result.append(matrix[bottom][c])
            bottom -= 1

        # 4. Traverse left column (if valid)
        if left <= right:
            for r in range(bottom, top - 1, -1):
                result.append(matrix[r][left])
            left += 1

    return result
TypeScript: Fast Array Boundary Contraction
function spiralOrder(matrix: number[][]): number[] {
  if (matrix.length === 0) return [];

  let top = 0;
  let bottom = matrix.length - 1;
  let left = 0;
  let right = matrix[0].length - 1;
  const result: number[] = [];

  while (top <= bottom && left <= right) {
    // 1. Top row
    for (let c = left; c <= right; c++) {
      result.push(matrix[top][c]);
    }
    top++;

    // 2. Right column
    for (let r = top; r <= bottom; r++) {
      result.push(matrix[r][right]);
    }
    right--;

    // 3. Bottom row (guarded)
    if (top <= bottom) {
      for (let c = right; c >= left; c--) {
        result.push(matrix[bottom][c]);
      }
      bottom--;
    }

    // 4. Left column (guarded)
    if (left <= right) {
      for (let r = bottom; r >= top; r--) {
        result.push(matrix[r][left]);
      }
      left++;
    }
  }

  return result;
}
Java 21: ArrayList Inward Contraction
import java.util.ArrayList;
import java.util.List;

public class Solution {
    public List spiralOrder(int[][] matrix) {
        List result = new ArrayList<>();
        if (matrix == null || matrix.length == 0) return result;

        int top = 0;
        int bottom = matrix.length - 1;
        int left = 0;
        int right = matrix[0].length - 1;

        while (top <= bottom && left <= right) {
            // 1. Top row
            for (int c = left; c <= right; c++) {
                result.add(matrix[top][c]);
            }
            top++;

            // 2. Right column
            for (int r = top; r <= bottom; r++) {
                result.add(matrix[r][right]);
            }
            right--;

            // 3. Bottom row (guarded)
            if (top <= bottom) {
                for (int c = right; c >= left; c--) {
                    result.add(matrix[bottom][c]);
                }
                bottom--;
            }

            // 4. Left column (guarded)
            if (left <= right) {
                for (int r = bottom; r >= top; r--) {
                    result.add(matrix[r][left]);
                }
                left++;
            }
        }

        return result;
    }
}
