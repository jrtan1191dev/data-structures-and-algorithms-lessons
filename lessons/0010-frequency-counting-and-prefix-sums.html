Frequency Counting & Prefix Sums

Mastering two indispensable interview patterns: canonical key grouping with frequency maps, and the cumulative prefix sum difference identity P[j] - P[i] = K.

Two distinct yet complementary techniques frequently appear in technical coding interviews: Frequency Counting (grouping items by common signatures) and Prefix Sums (accumulating running state to evaluate ranges in $O(1)$).

💡

Tied to Your Interview Mission

When an interview problem asks to count subarrays with a specific sum (even with negative numbers where sliding window fails!), your immediate reflex must be Prefix Sums + Hash Map. It transforms an $O(n^2)$ subarray scan into a single-pass $O(n)$ count.

1. Frequency Maps & Canonical Key Serialization

To group related items (like anagrams) together in a hash map, we need a canonical key that is identical for all variations of that group.

  • Method A (Sorting): Sort the characters: "eat" -> "aet", "tea" -> "aet". Cost: $O(k \log k)$ per word of length k.
  • Method B (Frequency Tuple): Count character frequencies: an array of 26 integers: [1, 0, ..., 1, 1] serialized as a string or tuple. Cost: strictly $O(k)$ linear time.

2. Grind 75 Questions & Key Learning Points

Key Learning Point: Use a fixed 26-element integer array instead of a generic hash map to avoid hash overhead and dynamic heap allocations. Increment for s, decrement for t, and verify all buckets equal 0.

Group Anagrams

Key Learning Point: Map canonical_signature -> list_of_words in a hash map. Serializing character frequency counts produces an $O(n \times k)$ optimal runtime.

LeetCode 560 • Medium Grind 75 Core
Subarray Sum Equals K

Key Learning Point: Maintain a running prefix sum. If running_sum - k was previously recorded in the frequency map, every occurrence represents a valid contiguous subarray ending at the current index!

LeetCode 128 • Medium Grind 75 Week 6
Longest Consecutive Sequence

Key Learning Point: Put all numbers into a hash set. Only begin counting a streak if num - 1 is NOT in the set (i.e. num is the true start of a streak). This ensures each number is checked at most twice → strictly $O(n)$ time!

3. Prefix Sum Mechanics: Instant O(1) Range Queries

A prefix sum array stores cumulative sums from index 0: 

nums:   [3,  4,  -2,   5,   1]
prefix: [0,  3,   7,   5,  10,  11]  (with prefix[0] = 0)

To compute sum of nums[1 ... 3] (4 + -2 + 5 = 7):
sum(1, 3) = prefix[4] - prefix[1] = 10 - 3 = 7   --> Instant O(1)!

4. The Difference Identity: Subarray Sum Equals K

We want to find subarrays where $\text{sum}(i, j) = k$. Using our prefix sum identity: 

prefix[j] - prefix[i] = k  ===>  prefix[i] = prefix[j] - k

As we iterate through the array maintaining a current_sum, we ask: "How many times did we encounter a prefix sum equal to current_sum - k in the past?" By recording prefix sum counts in a hash map, we answer this in O(1) time.

Crucial Base Case: Always initialize seen_prefix = {0: 1} to handle subarrays that start from index 0!

5. Multi-Language Implementations

Optimal implementation of Subarray Sum Equals K (LeetCode 560) in $O(n)$ time and $O(n)$ space: 

def subarray_sum(nums: list[int], k: int) -> int:
    """
    LeetCode 560 (Grind 75) - Prefix Sum + Hash Map.
    Time Complexity:  O(n) - single pass over nums.
    Space Complexity: O(n) - prefix sum frequency map.
    """
    count = 0
    current_sum = 0
    prefix_freq = {0: 1}  # Base case: prefix sum of 0 occurred once

    for num in nums:
        current_sum += num
        diff = current_sum - k

        if diff in prefix_freq:
            count += prefix_freq[diff]

        prefix_freq[current_sum] = prefix_freq.get(current_sum, 0) + 1

    return count
function subarraySum(nums: number[], k: number): number {
    // Time Complexity:  O(n)
    // Space Complexity: O(n)
    let count = 0;
    let currentSum = 0;
    const prefixFreq = new Map();
    prefixFreq.set(0, 1); // Base case

    for (let i = 0; i < nums.length; i++) {
        currentSum += nums[i];
        const diff = currentSum - k;

        if (prefixFreq.has(diff)) {
            count += prefixFreq.get(diff)!;
        }

        prefixFreq.set(currentSum, (prefixFreq.get(currentSum) || 0) + 1);
    }

    return count;
}
import java.util.HashMap;

public class SubarraySum {
    /**
     * LeetCode 560 (Grind 75) in O(n) time and O(n) space.
     */
    public static int subarraySum(int[] nums, int k) {
        int count = 0;
        int currentSum = 0;
        HashMap<Integer, Integer> prefixFreq = new HashMap<>();
        prefixFreq.put(0, 1); // Base case

        for (int num : nums) {
            currentSum += num;
            int diff = currentSum - k;

            if (prefixFreq.containsKey(diff)) {
                count += prefixFreq.get(diff);
            }

            prefixFreq.put(currentSum, prefixFreq.getOrDefault(currentSum, 0) + 1);
        }

        return count;
    }
}
