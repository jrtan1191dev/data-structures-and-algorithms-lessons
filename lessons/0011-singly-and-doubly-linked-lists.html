While arrays rely on an unbroken, contiguous block of memory where random access is computed by mathematical offsets, Linked Lists abandon contiguous memory entirely. Each element is an independently allocated node in the heap that holds a payload and an explicit pointer/reference to the next node.

💡

Tied to Your Interview Mission

Linked lists test your pointer discipline. Interviewers want to see whether you can rewire pointers in place without losing reference to remaining nodes, and whether you cleanly handle edge cases (empty lists, single-node lists, deleting head or tail) without crashing.

1. RAM Architecture: Contiguous Arrays vs. Heap Nodes

In an array, elements are neighbors in RAM (instant cache locality). In a linked list, nodes are scattered across the heap: 

Heap Memory Allocation:
Node A [Val: 10 | Next: 0x4080] lives at 0x1000
Node B [Val: 20 | Next: 0x2040] lives at 0x4080
Node C [Val: 30 | Next: null  ] lives at 0x2040

Traversal: To reach Node C, you MUST traverse A -> B -> C sequentially.
Cost: O(n) access time. You cannot calculate address by index!

The Trade-off: Inserting or deleting a node after a known pointer is strictly O(1) time (just redirect two pointers; no elements need shifting), whereas array insertions cost O(n).

2. Grind 75 Questions & Key Learning Points

LeetCode 206 • Easy Grind 75 Week 2
Reverse Linked List

Key Learning Point: Master the 3-pointer pattern: prev = null, curr = head, next_temp = curr.next. Rewire curr.next = prev and advance pointers. Avoid recursive reversal to save $O(n)$ stack space.

LeetCode 876 • Easy Grind 75 Week 3
Middle of the Linked List

Key Learning Point: Fast/slow pointers. When fast reaches the end (or fast.next == null), slow is precisely at the middle node in a single pass without computing total length first.

LeetCode 19 • Medium Grind 75 Week 5
Remove Nth Node From End of List

Key Learning Point: Maintain a fixed gap of $n$ nodes between fast and slow. Advance fast by $n$ steps from a dummy node. Then advance both together until fast.next == null; slow.next = slow.next.next deletes the target node cleanly in one pass.

3. The 3-Pointer In-Place Reversal Algorithm

Initial:
prev = null, curr = [1], next = [2] -> [3] -> null

Step 1: Save next node:        next_temp = curr.next
Step 2: Reverse current link:  curr.next = prev
Step 3: Advance prev:          prev = curr
Step 4: Advance curr:          curr = next_temp

When curr == null, prev points to the brand new head [3]!

Runs in strictly O(n) time and O(1) space.

4. The Fixed-Gap Technique: Remove Nth Node From End

To remove the $n$-th node from the end without traversing twice:

  1. Create a dummy node pointing to head. This handles the case where the head itself is deleted!
  2. Place both fast and slow at dummy.
  3. Advance fast forward by $n$ steps.
  4. Advance both fast and slow one step at a time until fast.next == null.
  5. Now slow is sitting directly before the target node → slow.next = slow.next.next.

5. Multi-Language Implementations: Reverse Linked List

Solving LeetCode 206 (Grind 75) in $O(n)$ time and $O(1)$ space across Python, TypeScript, and Java: 

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

def reverse_list(head: ListNode | None) -> ListNode | None:
    """
    LeetCode 206 (Grind 75) - In-place 3-pointer reversal.
    Time Complexity:  O(n) single traversal.
    Space Complexity: O(1) in-place rewiring.
    """
    prev = None
    curr = head

    while curr:
        next_temp = curr.next  # 1. Save next reference
        curr.next = prev       # 2. Reverse pointer
        prev = curr            # 3. Advance prev
        curr = next_temp       # 4. Advance curr

    return prev  # New head of reversed list
class ListNode {
    val: number;
    next: ListNode | null;
    constructor(val?: number, next?: ListNode | null) {
        this.val = val === undefined ? 0 : val;
        this.next = next === undefined ? null : next;
    }
}

function reverseList(head: ListNode | null): ListNode | null {
    // Time Complexity:  O(n)
    // Space Complexity: O(1)
    let prev: ListNode | null = null;
    let curr: ListNode | null = head;

    while (curr !== null) {
        const nextTemp: ListNode | null = curr.next;
        curr.next = prev;
        prev = curr;
        curr = nextTemp;
    }

    return prev;
}
public class ListNode {
    int val;
    ListNode next;
    ListNode(int val) { this.val = val; }
}

public class ReverseLinkedList {
    /**
     * LeetCode 206 (Grind 75) in O(n) time and O(1) auxiliary space.
     */
    public static ListNode reverseList(ListNode head) {
        ListNode prev = null;
        ListNode curr = head;

        while (curr != null) {
            ListNode nextTemp = curr.next; // 1. Save next node
            curr.next = prev;              // 2. Reverse link
            prev = curr;                   // 3. Step prev forward
            curr = nextTemp;               // 4. Step curr forward
        }

        return prev;
    }
}
