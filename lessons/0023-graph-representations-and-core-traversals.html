Graph Representations & Core Traversals

Memory layout trade-offs between adjacency matrices and adjacency lists, connected components identification, and multi-source BFS wave propagation.

1. Memory & Architecture

Adjacency Matrix vs Adjacency List in RAM

How a graph is laid out in memory fundamentally governs performance, cache utilization, and memory scaling:

Representation RAM Footprint Edge Lookup $(u, v)$ Iterate Neighbors of $u$ Cache Profile & Best Use Case
Adjacency Matrix $O(V^2)$ contiguous bytes $O(1)$ direct array index $O(V)$ scan across row Excellent spatial locality. Best for dense graphs ($E \approx V^2$) or small fixed $V$.
Adjacency List $O(V + E)$ array of pointers/lists $O(\text{deg}(u))$ scan $O(\text{deg}(u))$ direct access Scattered memory allocations unless packed into a flattened offset CSR array. Optimal for sparse graphs ($E \ll V^2$).

Connected Components and Flood Fill Mechanics

In an undirected graph, connected components form disjoint subgraphs. We can count components by iterating through all vertices $0 \dots V-1$; whenever an unvisited vertex is encountered, increment the component counter and execute a full traversal (DFS or BFS) to mark all reachable nodes visited. In grid problems, mutating land cells ('1' → '0') directly eliminates auxiliary visited arrays.

Multi-Source BFS for Simultaneous Wavefront Propagation

When computing shortest paths from multiple origins simultaneously (e.g. LC 542 01 Matrix or LC 994 Rotting Oranges), running separate BFS traversals from each source takes $O(K \cdot V)$. Instead, seed the FIFO queue with all source coordinates upfront at time 0. As the queue unrolls, the frontier expands uniformly across the entire graph in a single $O(V + E)$ pass.

3. Trilingual Reference Implementations

LC 200: Number of Islands (In-Place Memory Sink DFS)

Python 3: In-Place Mutation Island Sink
from typing import List

def numIslands(grid: List[List[str]]) -> int:
    if not grid:
        return 0

    rows, cols = len(grid), len(grid[0])
    islands = 0

    def dfs(r: int, c: int):
        if r < 0 or r >= rows or c < 0 or c >= cols or grid[r][c] != '1':
            return
        
        # Sink the land cell in RAM to prevent revisitation
        grid[r][c] = '0'

        dfs(r + 1, c)
        dfs(r - 1, c)
        dfs(r, c + 1)
        dfs(r, c - 1)

    for r in range(rows):
        for c in range(cols):
            if grid[r][c] == '1':
                islands += 1
                dfs(r, c)

    return islands
TypeScript: In-Place Island Sink DFS
function numIslands(grid: string[][]): number {
  if (!grid || grid.length === 0) return 0;

  const rows = grid.length;
  const cols = grid[0].length;
  let count = 0;

  function dfs(r: number, c: number): void {
    if (r < 0 || r >= rows || c < 0 || c >= cols || grid[r][c] !== "1") {
      return;
    }

    grid[r][c] = "0"; // In-place sink

    dfs(r + 1, c);
    dfs(r - 1, c);
    dfs(r, c + 1);
    dfs(r, c - 1);
  }

  for (let r = 0; r < rows; r++) {
    for (let c = 0; c < cols; c++) {
      if (grid[r][c] === "1") {
        count++;
        dfs(r, c);
      }
    }
  }

  return count;
}
Java 21: Primitive char[][] Mutation DFS
public class Solution {
    public int numIslands(char[][] grid) {
        if (grid == null || grid.length == 0) return 0;

        int rows = grid.length;
        int cols = grid[0].length;
        int islands = 0;

        for (int r = 0; r < rows; r++) {
            for (int c = 0; c < cols; c++) {
                if (grid[r][c] == '1') {
                    islands++;
                    sink(grid, r, c);
                }
            }
        }
        return islands;
    }

    private void sink(char[][] grid, int r, int c) {
        if (r < 0 || r >= grid.length || c < 0 || c >= grid[0].length || grid[r][c] != '1') {
            return;
        }

        grid[r][c] = '0'; // Mutate directly in RAM

        sink(grid, r + 1, c);
        sink(grid, r - 1, c);
        sink(grid, r, c + 1);
        sink(grid, r, c - 1);
    }
}
