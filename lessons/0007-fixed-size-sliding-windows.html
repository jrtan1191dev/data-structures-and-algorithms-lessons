Fixed-Size Sliding Windows

Reusing interval state across contiguous subarrays. How moving a fixed frame of size k turns repeated O(k) recomputations into instantaneous O(1) state updates.

In many interview problems, you are asked to compute an aggregate (sum, average, maximum, anagram match) over every contiguous subarray or substring of fixed length k.

💡

Tied to Your Interview Mission

The brute-force solution re-evaluates all k elements for every starting position, costing O(n × k). By observing that adjacent windows share $k - 1$ overlapping elements, we subtract the exiting element and add the entering element in O(1) time per step, yielding a strictly O(n) linear runtime.

1. The State Reuse Mental Model

Consider an array [1, 3, 2, 6, -1, 4, 1] with window size k = 4: 

Window 0: [1,  3,  2,  6]           Sum = 12
Window 1:     [3,  2,  6, -1]       Sum = 12 - 1 + (-1) = 10
Window 2:         [2,  6, -1,  4]   Sum = 10 - 3 + 4    = 11
Window 3:             [6, -1,  4, 1]Sum = 11 - 2 + 1    = 10

Only 1 element leaves and 1 element enters!
All middle (k - 2) elements remain unchanged.

2. Grind 75 Problems & Key Learning Takeaways

Here are the canonical Grind 75 problems governed by the Fixed-Size Sliding Window pattern:

LeetCode 643 • Easy Grind 75
Maximum Average Subarray I

Key Learning Takeaway: Build the initial window sum of the first k items in $O(k)$. Then slide from $i = k$ to $n-1$: window_sum += nums[i] - nums[i - k]. Never re-sum!

LeetCode 567 • Medium Grind 75
Permutation in String

Key Learning Takeaway: A permutation of s1 inside s2 is simply an anagram of exact length len(s1). Use a fixed window of size len(s1) over s2 with a 26-element character frequency array. Maintain a matches count (number of characters whose frequencies match) to verify equality in $O(1)$ rather than comparing 26 buckets every step.

LeetCode 438 • Medium Grind 75
Find All Anagrams in a String

Key Learning Takeaway: Extends LeetCode 567 by collecting every starting index where the fixed window's frequency vector equals the pattern's frequency vector.

3. The O(1) Update Formula: Enter & Exit Mechanics

Every fixed-window algorithm follows this invariant template: 

1. INITIALIZE:
   Compute state for window [0 ... k - 1]

2. SLIDE (for i from k to n - 1):
   entering_item = nums[i]
   exiting_item  = nums[i - k]

   update_state_add(entering_item)
   update_state_remove(exiting_item)

   record_best_result()

4. Multi-Language Implementations: Permutation in String

Solving LeetCode 567 (Grind 75) in optimal $O(n)$ time and $O(1)$ auxiliary space across Python, TypeScript, and Java: 

def check_inclusion(s1: str, s2: str) -> bool:
    """
    LeetCode 567 (Grind 75) - Fixed Window of size len(s1).
    Time Complexity:  O(len(s2)) - single linear pass.
    Space Complexity: O(1) - two 26-element frequency arrays.
    """
    n1, n2 = len(s1), len(s2)
    if n1 > n2:
        return False

    s1_counts = [0] * 26
    s2_counts = [0] * 26

    # 1. Initialize first window
    for i in range(n1):
        s1_counts[ord(s1[i]) - ord('a')] += 1
        s2_counts[ord(s2[i]) - ord('a')] += 1

    matches = sum(1 for c in range(26) if s1_counts[c] == s2_counts[c])

    # 2. Slide window of size n1 across s2
    for i in range(n1, n2):
        if matches == 26:
            return True

        # Character entering window on right
        r_idx = ord(s2[i]) - ord('a')
        s2_counts[r_idx] += 1
        if s2_counts[r_idx] == s1_counts[r_idx]:
            matches += 1
        elif s2_counts[r_idx] == s1_counts[r_idx] + 1:
            matches -= 1

        # Character exiting window on left
        l_idx = ord(s2[i - n1]) - ord('a')
        s2_counts[l_idx] -= 1
        if s2_counts[l_idx] == s1_counts[l_idx]:
            matches += 1
        elif s2_counts[l_idx] == s1_counts[l_idx] - 1:
            matches -= 1

    return matches == 26
function checkInclusion(s1: string, s2: string): boolean {
    const n1 = s1.length;
    const n2 = s2.length;
    if (n1 > n2) return false;

    const s1Count = new Int32Array(26);
    const s2Count = new Int32Array(26);
    const codeA = 'a'.charCodeAt(0);

    // Initialize first window of size n1
    for (let i = 0; i < n1; i++) {
        s1Count[s1.charCodeAt(i) - codeA]++;
        s2Count[s2.charCodeAt(i) - codeA]++;
    }

    let matches = 0;
    for (let i = 0; i < 26; i++) {
        if (s1Count[i] === s2Count[i]) matches++;
    }

    // Slide across s2
    for (let i = n1; i < n2; i++) {
        if (matches === 26) return true;

        const enterIdx = s2.charCodeAt(i) - codeA;
        s2Count[enterIdx]++;
        if (s2Count[enterIdx] === s1Count[enterIdx]) matches++;
        else if (s2Count[enterIdx] === s1Count[enterIdx] + 1) matches--;

        const exitIdx = s2.charCodeAt(i - n1) - codeA;
        s2Count[exitIdx]--;
        if (s2Count[exitIdx] === s1Count[exitIdx]) matches++;
        else if (s2Count[exitIdx] === s1Count[exitIdx] - 1) matches--;
    }

    return matches === 26;
}
public class PermutationInString {
    /**
     * LeetCode 567 (Grind 75) in O(n2) time and O(1) auxiliary space.
     */
    public static boolean checkInclusion(String s1, String s2) {
        int n1 = s1.length();
        int n2 = s2.length();
        if (n1 > n2) return false;

        int[] s1Counts = new int[26];
        int[] s2Counts = new int[26];

        for (int i = 0; i < n1; i++) {
            s1Counts[s1.charAt(i) - 'a']++;
            s2Counts[s2.charAt(i) - 'a']++;
        }

        int matches = 0;
        for (int i = 0; i < 26; i++) {
            if (s1Counts[i] == s2Counts[i]) matches++;
        }

        for (int i = n1; i < n2; i++) {
            if (matches == 26) return true;

            int enterIdx = s2.charAt(i) - 'a';
            s2Counts[enterIdx]++;
            if (s2Counts[enterIdx] == s1Counts[enterIdx]) matches++;
            else if (s2Counts[enterIdx] == s1Counts[enterIdx] + 1) matches--;

            int exitIdx = s2.charAt(i - n1) - 'a';
            s2Counts[exitIdx]--;
            if (s2Counts[exitIdx] == s1Counts[exitIdx]) matches++;
            else if (s2Counts[exitIdx] == s1Counts[exitIdx] - 1) matches--;
        }

        return matches == 26;
    }
}
