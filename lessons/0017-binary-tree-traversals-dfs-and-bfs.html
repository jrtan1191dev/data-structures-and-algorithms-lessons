Binary Tree Traversals: DFS & BFS

Recursive divide-and-conquer call stacks, bottom-up tree invariants (height, diameter, balance), and batch level-order processing via queue snapshots.

Trees are hierarchical, non-linear data structures. Every tree problem is fundamentally solved by dividing the problem into two subproblems: what needs to be done on the left child, what needs to be done on the right child, and how to combine them at the root.

💡

Tied to Your Interview Mission

Nearly 20% of Grind 75 problems involve binary trees. The secret to writing clean code without messy state tracking is choosing the correct traversal: Pre-Order for top-down construction, Post-Order for bottom-up metric aggregation, and BFS for shortest paths and level-by-level outputs.

1. The Recursive Tree Invariant

A binary tree node contains a value and references to two subtrees: 

TreeNode {
   val: int
   left: TreeNode | null
   right: TreeNode | null
}

Every binary tree problem has the identical base case: 

if root is None: return base_value

For Maximum Depth (LeetCode 104), the height of any tree is simply: 

Height(node) = 1 + max(Height(node.left), Height(node.right))

2. Grind 75 Questions & Key Learning Points

LeetCode 226 • Easy Grind 75 Week 1
Invert Binary Tree

Key Learning Point: Maximize simplicity: recursively invert both subtrees, then swap references in place: root.left, root.right = invert(root.right), invert(root.left).

LeetCode 104 • Easy Grind 75 Week 2
Maximum Depth of Binary Tree

Key Learning Point: Post-order recursive DFS: compute depths of subtrees, add 1, and return to parent. Takes $O(n)$ time and $O(H)$ stack space.

LeetCode 110 • Easy Grind 75 Week 2
Balanced Binary Tree

Key Learning Point: Avoid naive top-down recursion which re-calculates depth at every node in $O(n^2)$. Use bottom-up post-order: return height if balanced, or return -1 immediately as an early-exit sentinel if $|h_L - h_R| > 1$. Total: strictly $O(n)$ time.

LeetCode 543 • Easy Grind 75 Week 2
Diameter of Binary Tree

Key Learning Point: The longest path between any two nodes may not pass through the root! At each node, path length is $h_L + h_R$. Update global maximum diameter while returning node height $1 + \max(h_L, h_R)$ up the recursion chain.

LeetCode 102 • Medium Grind 75 Week 3
Binary Tree Level Order Traversal

Key Learning Point: The queue snapshot pattern. Measure current queue length $S = \text{len}(q)$ before loop. Run $S$ iterations to dequeue all nodes in the current layer while enqueuing their children for the next layer.

3. DFS Traversal Strategies: Pre, In, and Post-Order

  • Pre-Order (Node, Left, Right): Process current node before its children. Used for duplicating or serializing trees.
  • In-Order (Left, Node, Right): Used on Binary Search Trees to visit elements in sorted numerical order.
  • Post-Order (Left, Right, Node): Process children first, then combine results at root. Mandatory for computing heights, subtree sizes, and bottom-up validations.

4. BFS Level-Order: The Queue Snapshot Pattern

def level_order(root):
    if not root: return []
    res = []
    q = deque([root])

    while q:
        level_size = len(q)  # SNAPSHOT: number of nodes in this exact level!
        current_level = []

        for _ in range(level_size):
            node = q.popleft()
            current_level.append(node.val)
            if node.left:  q.append(node.left)
            if node.right: q.append(node.right)

        res.append(current_level)

    return res

5. Multi-Language Implementations: Invert Tree & Level Order

Solving LeetCode 226 & 102 (Grind 75) across Python, TypeScript, and Java: 

from collections import deque

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

def invert_tree(root: TreeNode | None) -> TreeNode | None:
    """LeetCode 226 (Grind 75) - Recursive in-place swap."""
    if not root:
        return None
    root.left, root.right = invert_tree(root.right), invert_tree(root.left)
    return root

def level_order(root: TreeNode | None) -> list[list[int]]:
    """LeetCode 102 (Grind 75) - Queue Snapshot BFS."""
    if not root:
        return []
    res, q = [], deque([root])
    while q:
        level = []
        for _ in range(len(q)):
            node = q.popleft()
            level.append(node.val)
            if node.left: q.append(node.left)
            if node.right: q.append(node.right)
        res.append(level)
    return res
class TreeNode {
    val: number;
    left: TreeNode | null;
    right: TreeNode | null;
    constructor(val?: number, left?: TreeNode | null, right?: TreeNode | null) {
        this.val = val === undefined ? 0 : val;
        this.left = left === undefined ? null : left;
        this.right = right === undefined ? null : right;
    }
}

function invertTree(root: TreeNode | null): TreeNode | null {
    if (!root) return null;
    const temp = invertTree(root.left);
    root.left = invertTree(root.right);
    root.right = temp;
    return root;
}

function levelOrder(root: TreeNode | null): number[][] {
    if (!root) return [];
    const res: number[][] = [];
    const q: TreeNode[] = [root];

    while (q.length > 0) {
        const levelSize = q.length;
        const currentLevel: number[] = [];

        for (let i = 0; i < levelSize; i++) {
            const node = q.shift()!;
            currentLevel.push(node.val);
            if (node.left) q.push(node.left);
            if (node.right) q.push(node.right);
        }
        res.push(currentLevel);
    }
    return res;
}
import java.util.*;

public class TreeTraversals {
    public TreeNode invertTree(TreeNode root) {
        if (root == null) return null;
        TreeNode temp = invertTree(root.left);
        root.left = invertTree(root.right);
        root.right = temp;
        return root;
    }

    public List<List<Integer>> levelOrder(TreeNode root) {
        List<List<Integer>> res = new ArrayList<>();
        if (root == null) return res;

        Queue<TreeNode> q = new ArrayDeque<>();
        q.offer(root);

        while (!q.isEmpty()) {
            int levelSize = q.size();
            List<Integer> level = new ArrayList<>();

            for (int i = 0; i < levelSize; i++) {
                TreeNode node = q.poll();
                level.add(node.val);
                if (node.left != null) q.offer(node.left);
                if (node.right != null) q.offer(node.right);
            }
            res.add(level);
        }
        return res;
    }
}

Queue Snapshot
In Binary Tree Level Order Traversal (LeetCode 102), why must we record level_size = len(queue) before the inner dequeue loop?
Prevents queue memory buffers from overflowing
Allows binary search over queued tree nodes
Delineates nodes belonging to current level
Sorts children nodes by numerical values

Bottom-Up Pruning
Why does a bottom-up post-order traversal in Balanced Binary Tree (LeetCode 110) achieve O(n) time while top-down recursion requires O(n²)?
Subtree heights are passed upward without recomputation
Bottom-up approach skips left subtrees entirely
Allocates auxiliary hash maps for every node
Tree nodes are stored in contiguous array memory
