Binary Search Trees & Validation

The global BST invariant, why local parent-child checks fail, range boundary propagation (-∞, +∞), and O(H) Lowest Common Ancestor search.

A Binary Search Tree (BST) enforces an ordering rule that enables binary-search-like lookup in $O(H)$ time (where $H = \log n$ in balanced trees). However, validating and traversing BSTs requires strict adherence to global constraints.

💡

Tied to Your Interview Mission

The most common rookie mistake in interviews: writing if (node.left.val < node.val && node.right.val > node.val). This only checks immediate children! A descendant deep in the right subtree could easily be smaller than the root, violating the global BST property.

1. The Global BST Invariant & The Local Trap

        10
       /  \
      5    15
          /  \
         6    20    <-- INVALID BST! 
                     6 is greater than its parent (N/A) and less than 15,
                     BUT 6 is in the right subtree of 10!
                     6 < 10 violates the root invariant!

The Rule: Every node in the left subtree must be strictly less than the root, and every node in the right subtree must be strictly greater than the root.

2. Grind 75 Questions & Key Learning Points

LeetCode 98 • Medium Grind 75 Week 4
Validate Binary Search Tree

Key Learning Point: Pass allowable range bounds $(low, high)$ down the tree. For node.left, new range is $(low, node.val)$; for node.right, new range is $(node.val, high)$. Verify $low < node.val < high$ at every step.

LeetCode 235 • Easy Grind 75 Week 2
Lowest Common Ancestor of a BST

Key Learning Point: The split point insight. If both $p$ and $q$ are smaller than root, LCA must lie in the left subtree. If both are larger, LCA must lie in the right subtree. The moment $p$ and $q$ split to opposite sides (or one equals root), the current node IS the LCA! Runs in $O(H)$ time and $O(1)$ space without recursion stack.

LeetCode 230 • Medium Grind 75 Week 6
Kth Smallest Element in a BST

Key Learning Point: In-order traversal ($Left \to Root \to Right$) visits BST nodes in monotonically increasing order. Use an iterative in-order stack to stop early after processing $k$ nodes in $O(H + k)$ time.

3. The Range Propagation Pattern

def is_valid_bst(root):
    def validate(node, low, high):
        if not node:
            return True
        if not (low < node.val < high):
            return False
        return (validate(node.left, low, node.val) and 
                validate(node.right, node.val, high))

    return validate(root, float('-inf'), float('inf'))

4. Lowest Common Ancestor: The Split Point Insight

def lowest_common_ancestor(root, p, q):
    curr = root
    while curr:
        if p.val < curr.val and q.val < curr.val:
            curr = curr.left   # Both nodes in left subtree
        elif p.val > curr.val and q.val > curr.val:
            curr = curr.right  # Both nodes in right subtree
        else:
            return curr        # Split point! curr is LCA!

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

def is_valid_bst(root: TreeNode | None) -> bool:
    """LeetCode 98 (Grind 75) - Range boundary validation."""
    def validate(node, low, high):
        if not node: return True
        if not (low < node.val < high): return False
        return validate(node.left, low, node.val) and validate(node.right, node.val, high)
    return validate(root, float('-inf'), float('inf'))

def lowest_common_ancestor(root: TreeNode, p: TreeNode, q: TreeNode) -> TreeNode:
    """LeetCode 235 (Grind 75) - Iterative LCA in O(H) time and O(1) space."""
    curr = root
    while curr:
        if p.val < curr.val and q.val < curr.val:
            curr = curr.left
        elif p.val > curr.val and q.val > curr.val:
            curr = curr.right
        else:
            return curr
    return root
function isValidBST(root: TreeNode | null): boolean {
    function validate(node: TreeNode | null, low: number, high: number): boolean {
        if (!node) return true;
        if (node.val <= low || node.val >= high) return false;
        return validate(node.left, low, node.val) && validate(node.right, node.val, high);
    }
    return validate(root, -Infinity, Infinity);
}

function lowestCommonAncestor(root: TreeNode | null, p: TreeNode | null, q: TreeNode | null): TreeNode | null {
    let curr = root;
    while (curr) {
        if (p!.val < curr.val && q!.val < curr.val) {
            curr = curr.left;
        } else if (p!.val > curr.val && q!.val > curr.val) {
            curr = curr.right;
        } else {
            return curr;
        }
    }
    return null;
}
public class BSTProblems {
    public boolean isValidBST(TreeNode root) {
        return validate(root, null, null);
    }

    private boolean validate(TreeNode node, Integer low, Integer high) {
        if (node == null) return true;
        if ((low != null && node.val <= low) || (high != null && node.val >= high)) return false;
        return validate(node.left, low, node.val) && validate(node.right, node.val, high);
    }

    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        TreeNode curr = root;
        while (curr != null) {
            if (p.val < curr.val && q.val < curr.val) {
                curr = curr.left;
            } else if (p.val > curr.val && q.val > curr.val) {
                curr = curr.right;
            } else {
                return curr;
            }
        }
        return null;
    }
}
