The Top-K Elements & Two-Heaps Pattern

Bounded-size heaps for streaming extremes, balancing dual heaps for dynamic median extraction, and avoiding total $O(n \log n)$ array sorts.

1. Memory & Architecture

Bounded Heaps vs Full Sort

When searching for the $k$ largest elements in a dataset of size $N$ ($k \ll N$), sorting the entire array consumes $O(N \log N)$ time and $O(N)$ auxiliary memory (or mutates the input).

By maintaining a min-heap capped at size $k$, we process elements as a streaming pipeline:

  • For each incoming element $x$: push $x$ into the min-heap.
  • If heap size exceeds $k$, pop the root (which is the smallest of the top $k+1$ candidates).
  • Final State: The heap retains the $k$ largest elements encountered, and the root is the $k$-th largest. Total time is $O(N \log k)$ with $O(k)$ memory.

The Two-Heaps Pattern for Dynamic Streaming Medians

To track the median of an incoming number stream in $O(\log n)$ insertion and $O(1)$ query time, split the dataset into two balanced halves:

Two-Heaps Invariants
[ Lower Half: Max-Heap (small) ]  <=  [ Upper Half: Min-Heap (large) ]
                  |                                     |
              max_val                               min_val

Invariants to maintain after every insertion:
1. Ordering: max(small) <= min(large)
2. Size Balance: len(small) == len(large)  OR  len(small) == len(large) + 1

Median Extraction:
- If odd:   small[0]
- If even:  (small[0] + large[0]) / 2.0

Python 3: Dual Heaps with Negated Max-Heap Storage
import heapq

class MedianFinder:
    def __init__(self):
        # small: max-heap (invert signs for heapq)
        # large: min-heap
        self.small = []
        self.large = []

    def addNum(self, num: int) -> None:
        # Step 1: Push to max-heap first
        heapq.heappush(self.small, -num)
        
        # Step 2: Ensure small's largest <= large's smallest
        if self.small and self.large and (-self.small[0] > self.large[0]):
            val = -heapq.heappop(self.small)
            heapq.heappush(self.large, val)
            
        # Step 3: Enforce size invariant: len(small) == len(large) or len(small) == len(large) + 1
        if len(self.small) > len(self.large) + 1:
            val = -heapq.heappop(self.small)
            heapq.heappush(self.large, val)
        elif len(self.large) > len(self.small):
            val = heapq.heappop(self.large)
            heapq.heappush(self.small, -val)

    def findMedian(self) -> float:
        if len(self.small) > len(self.large):
            return float(-self.small[0])
        return (-self.small[0] + self.large[0]) / 2.0
TypeScript: Binary Heap Class with Custom Comparator
class CustomHeap {
  private heap: number[] = [];
  constructor(private compare: (a: number, b: number) => number) {}

  push(val: number): void {
    this.heap.push(val);
    let i = this.heap.length - 1;
    while (i > 0) {
      const p = Math.floor((i - 1) / 2);
      if (this.compare(this.heap[i], this.heap[p]) < 0) {
        [this.heap[i], this.heap[p]] = [this.heap[p], this.heap[i]];
        i = p;
      } else break;
    }
  }

  pop(): number {
    const top = this.heap[0];
    const bottom = this.heap.pop()!;
    if (this.heap.length > 0) {
      this.heap[0] = bottom;
      let i = 0;
      const n = this.heap.length;
      while (2 * i + 1 < n) {
        let best = 2 * i + 1;
        const right = 2 * i + 2;
        if (right < n && this.compare(this.heap[right], this.heap[best]) < 0) {
          best = right;
        }
        if (this.compare(this.heap[best], this.heap[i]) < 0) {
          [this.heap[i], this.heap[best]] = [this.heap[best], this.heap[i]];
          i = best;
        } else break;
      }
    }
    return top;
  }

  peek(): number { return this.heap[0]; }
  get size(): number { return this.heap.length; }
}

class MedianFinder {
  private small = new CustomHeap((a, b) => b - a); // Max-heap
  private large = new CustomHeap((a, b) => a - b); // Min-heap

  addNum(num: number): void {
    this.small.push(num);

    if (this.small.size > 0 && this.large.size > 0 && this.small.peek() > this.large.peek()) {
      this.large.push(this.small.pop());
    }

    if (this.small.size > this.large.size + 1) {
      this.large.push(this.small.pop());
    } else if (this.large.size > this.small.size) {
      this.small.push(this.large.pop());
    }
  }

  findMedian(): number {
    if (this.small.size > this.large.size) {
      return this.small.peek();
    }
    return (this.small.peek() + this.large.peek()) / 2;
  }
}
Java 21: Dual PriorityQueue Architecture
import java.util.Collections;
import java.util.PriorityQueue;

public class MedianFinder {
    private final PriorityQueue small; // Max-heap for lower half
    private final PriorityQueue large; // Min-heap for upper half

    public MedianFinder() {
        this.small = new PriorityQueue<>(Collections.reverseOrder());
        this.large = new PriorityQueue<>();
    }

    public void addNum(int num) {
        small.offer(num);

        // Enforce ordering invariant
        if (!small.isEmpty() && !large.isEmpty() && small.peek() > large.peek()) {
            large.offer(small.poll());
        }

        // Enforce size invariant
        if (small.size() > large.size() + 1) {
            large.offer(small.poll());
        } else if (large.size() > small.size()) {
            small.offer(large.poll());
        }
    }

    public double findMedian() {
        if (small.size() > large.size()) {
            return (double) small.peek();
        }
        return ((double) small.peek() + large.peek()) / 2.0;
    }
}
