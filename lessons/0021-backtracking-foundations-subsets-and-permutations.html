Backtracking Foundations: Subsets & Permutations

State-space tree exploration, the canonical Choose → Explore → Un-choose invariant, and mutable path buffer reuse over heap reallocation.

1. Memory & Architecture

The Anatomy of State-Space Trees

Backtracking is a depth-first traversal across an implicit state-space decision tree. At every tree node, the algorithm makes a candidate decision, descends deeper, and crucially undoes that decision upon return (backtracking) to restore pristine state for sibling branches.

Heap Allocation vs Mutable Call-Stack Reuse: A naive implementation passes newly copied arrays (e.g. path + [x]) down recursion. This allocates $O(N)$ memory per call stack frame, generating millions of transient objects and triggering heavy garbage collector pressure. The canonical pattern maintains a single mutable array buffer on the heap, pushes the candidate, recurses, and pops it back off (costing $O(1)$ amortized per step). Deep copies are taken only when adding a valid state to the results list.

Subsets ($2^N$) vs Permutations ($N!$) Decision Models

  • Subsets (Powerset): At each index $i$, we choose whether to include or exclude nums[i] (binary decision tree of depth $N$, total leaves $2^N$), or we branch across all remaining indices $\ge i$ to avoid permutations of identical sets.
  • Permutations: Ordering matters. Every unused candidate in the entire array is eligible at each step. We track used candidates via a boolean array or bitmask, branching across all unvisited elements (tree branch factor $N, N-1, \dots, 1$, total leaves $N!$).

3. Trilingual Reference Implementations

LC 46: Permutations (Choose → Explore → Un-choose)

Python 3: Single Mutable Buffer Backtracking
from typing import List

def permute(nums: List[int]) -> List[List[int]]:
    results: List[List[int]] = []
    used = [False] * len(nums)
    path: List[int] = []

    def backtrack():
        # Base case: full permutation formed
        if len(path) == len(nums):
            results.append(path[:])  # Take snapshot copy
            return

        for i in range(len(nums)):
            if not used[i]:
                # Choose
                used[i] = True
                path.append(nums[i])

                # Explore
                backtrack()

                # Un-choose (Backtrack)
                path.pop()
                used[i] = False

    backtrack()
    return results
TypeScript: Mutable Path and Boolean Mask
function permute(nums: number[]): number[][] {
  const results: number[][] = [];
  const used = new Array(nums.length).fill(false);
  const path: number[] = [];

  function backtrack(): void {
    if (path.length === nums.length) {
      results.push([...path]); // Clone current path
      return;
    }

    for (let i = 0; i < nums.length; i++) {
      if (!used[i]) {
        // Choose
        used[i] = true;
        path.push(nums[i]);

        // Explore
        backtrack();

        // Un-choose
        path.pop();
        used[i] = false;
      }
    }
  }

  backtrack();
  return results;
}
Java 21: ArrayList Backtracking with Boolean Array
import java.util.ArrayList;
import java.util.List;

public class Solution {
    public List> permute(int[] nums) {
        List> results = new ArrayList<>();
        boolean[] used = new boolean[nums.length];
        backtrack(nums, used, new ArrayList<>(), results);
        return results;
    }

    private void backtrack(int[] nums, boolean[] used, List path, List> results) {
        if (path.size() == nums.length) {
            results.add(new ArrayList<>(path)); // Deep copy snapshot
            return;
        }

        for (int i = 0; i < nums.length; i++) {
            if (!used[i]) {
                // Choose
                used[i] = true;
                path.add(nums[i]);

                // Explore
                backtrack(nums, used, path, results);

                // Un-choose
                path.remove(path.size() - 1);
                used[i] = false;
            }
        }
    }
}
