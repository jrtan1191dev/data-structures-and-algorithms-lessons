Topological Sort & Disjoint Set Union

Dependency ordering via in-degree Kahn queues, cycle detection in DAGs, and near-constant time dynamic connectivity via DSU with path compression.

1. Memory & Architecture

Kahn's In-Degree Reduction vs DFS Cycle Coloring

A topological sort of a directed acyclic graph (DAG) produces a linear sequence of vertices such that for every directed edge $u \to v$, vertex $u$ comes before $v$.

Kahn's Algorithm computes in-degrees for all vertices. A FIFO queue holds all nodes with in_degree == 0 (unblocked dependencies):

  • Pop vertex $u$ from the queue and record it in the topological order.
  • For every neighbor $v$ of $u$, decrement $v$'s in-degree by 1.
  • If $v$'s in-degree drops to 0, push $v$ into the queue.
  • Cycle Check: If the count of recorded nodes is strictly less than $V$, the graph contains a directed cycle (deadlock).

Disjoint Set Union (DSU) & Path Compression

DSU models dynamic connectivity partitions in a single flat array parent[]:

Path Compression & Union by Rank
// Two essential optimizations:
1. Path Compression: Recursively reparent every visited node directly to the root:
   find(x):
     if parent[x] != x:
       parent[x] = find(parent[x])
     return parent[x]

2. Union by Rank: Always attach the shallower root under the deeper root.

Result: Almost constant amortized time per operation: O(alpha(N)) <= 4 operations!

LC 207: Course Schedule (Kahn's BFS In-Degree Algorithm)

Python 3: Kahn's In-Degree Reduction
from collections import deque
from typing import List

def canFinish(numCourses: int, prerequisites: List[List[int]]) -> bool:
    adj = [[] for _ in range(numCourses)]
    in_degree = [0] * numCourses

    # Build adjacency list and compute in-degrees
    for dest, src in prerequisites:
        adj[src].append(dest)
        in_degree[dest] += 1

    # Seed queue with courses having 0 prerequisites
    queue = deque([i for i in range(numCourses) if in_degree[i] == 0])
    completed = 0

    while queue:
        curr = queue.popleft()
        completed += 1

        for neighbor in adj[curr]:
            in_degree[neighbor] -= 1
            if in_degree[neighbor] == 0:
                queue.append(neighbor)

    return completed == numCourses
TypeScript: Array Queue Kahn's Algorithm
function canFinish(numCourses: number, prerequisites: number[][]): boolean {
  const adj: number[][] = Array.from({ length: numCourses }, () => []);
  const inDegree = new Array(numCourses).fill(0);

  for (const [dest, src] of prerequisites) {
    adj[src].push(dest);
    inDegree[dest]++;
  }

  const queue: number[] = [];
  for (let i = 0; i < numCourses; i++) {
    if (inDegree[i] === 0) queue.push(i);
  }

  let head = 0;
  let completed = 0;

  while (head < queue.length) {
    const curr = queue[head++];
    completed++;

    for (const neighbor of adj[curr]) {
      inDegree[neighbor]--;
      if (inDegree[neighbor] === 0) {
        queue.push(neighbor);
      }
    }
  }

  return completed === numCourses;
}
Java 21: ArrayDeque Kahn's Algorithm
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.List;
import java.util.Queue;

public class Solution {
    public boolean canFinish(int numCourses, int[][] prerequisites) {
        List> adj = new ArrayList<>();
        for (int i = 0; i < numCourses; i++) {
            adj.add(new ArrayList<>());
        }

        int[] inDegree = new int[numCourses];
        for (int[] edge : prerequisites) {
            int dest = edge[0];
            int src = edge[1];
            adj.get(src).add(dest);
            inDegree[dest]++;
        }

        Queue queue = new ArrayDeque<>();
        for (int i = 0; i < numCourses; i++) {
            if (inDegree[i] == 0) {
                queue.offer(i);
            }
        }

        int completed = 0;
        while (!queue.isEmpty()) {
            int curr = queue.poll();
            completed++;

            for (int neighbor : adj.get(curr)) {
                inDegree[neighbor]--;
                if (inDegree[neighbor] == 0) {
                    queue.offer(neighbor);
                }
            }
        }

        return completed == numCourses;
    }
}
