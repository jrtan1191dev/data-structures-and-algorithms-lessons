Stacks, Queues & Deques

LIFO vs. FIFO memory models, avoiding O(n) array shift traps with ring buffers and deques, and building O(1) tracking structures like Min Stack.

Stacks (Last-In, First-Out) and Queues (First-In, First-Out) restrict access to elements to guarantee strict ordering semantics. They form the backbone of language execution runtimes (the call stack) and foundational search algorithms (DFS and BFS).

💡

Tied to Your Interview Mission

In technical interviews, using a standard array as a queue via arr.pop(0) in Python or arr.shift() in JavaScript is an instant red flag. It triggers hidden O(n) memory copying on every dequeue! You must use collections.deque in Python, a ring buffer / ArrayDeque in Java, or a pointer-based queue in TypeScript.

1. LIFO vs. FIFO Underlying Mechanics

  • Stack (LIFO): Elements are added and removed from the same end (the top). Because append and pop from the tail of a dynamic array don't shift elements, standard arrays make optimal O(1) stacks.
  • Queue (FIFO): Elements enter at the tail (enqueue) and exit at the head (dequeue). Removing from index 0 in a regular array requires shifting all remaining items left → O(n). To achieve O(1) dequeues, queues use a circular buffer or a doubly linked list (Deque).

2. Grind 75 Questions & Key Learning Points

LeetCode 20 • Easy Grind 75 Week 1
Valid Parentheses

Key Learning Point: Push expected closing brackets (or push opening brackets and map to closing types via a hash map). When encountering a closing bracket, pop and verify equality. Verify len(stack) == 0 at the end to catch unclosed opening brackets!

LeetCode 232 • Easy Grind 75 Week 2
Implement Queue using Stacks

Key Learning Point: Dual-stack architecture (in_stack and out_stack). Push directly to in_stack in $O(1)$. When popping, only dump in_stack into out_stack when out_stack is empty. Each element is transferred at most once → $O(1)$ amortized!

LeetCode 155 • Medium Grind 75 Week 3
Min Stack

Key Learning Point: Track the running minimum at every stack depth. Store pairs (val, current_min) in a single stack, or maintain a secondary min_stack. getMin() returns top of the min-tracker in strictly $O(1)$ time.

LeetCode 150 • Medium Grind 75 Week 3
Evaluate Reverse Polish Notation

Key Learning Point: Postfix evaluation. Operands are pushed onto stack. When an operator is met, pop top two operands (caution: order matters! b = pop(), a = pop() → compute a op b) and push the result back.

3. The Queue Performance Trap: Pop(0) vs. Deque

Python:
from collections import deque
q = deque()
q.append(10)      # O(1)
q.popleft()       # O(1)  <-- NEVER use list.pop(0) which is O(n)!

Java:
Deque q = new ArrayDeque<>();
q.offerLast(10);  # O(1)
q.pollFirst();    # O(1)  <-- Faster than LinkedList in RAM!

4. Multi-Language Implementations: Valid Parentheses & Min Stack

Solving LeetCode 20 & 155 (Grind 75) in $O(n)$ time and $O(n)$ space: 

def is_valid_parentheses(s: str) -> bool:
    """
    LeetCode 20 (Grind 75) - Stack LIFO matching.
    Time Complexity:  O(n) - single pass.
    Space Complexity: O(n) - stack memory.
    """
    bracket_map = {')': '(', '}': '{', ']': '['}
    stack = []

    for char in s:
        if char in bracket_map:
            # Must match top of stack
            top_element = stack.pop() if stack else '#'
            if bracket_map[char] != top_element:
                return False
        else:
            stack.append(char)

    return len(stack) == 0

class MinStack:
    """
    LeetCode 155 (Grind 75) - O(1) push, pop, top, getMin.
    """
    def __init__(self):
        self.stack = []  # stores (val, min_so_far) tuples

    def push(self, val: int) -> None:
        current_min = val if not self.stack else min(val, self.stack[-1][1])
        self.stack.append((val, current_min))

    def pop(self) -> None:
        self.stack.pop()

    def top(self) -> int:
        return self.stack[-1][0]

    def getMin(self) -> int:
        return self.stack[-1][1]
function isValid(s: string): boolean {
    const map: Record = { ')': '(', '}': '{', ']': '[' };
    const stack: string[] = [];

    for (let i = 0; i < s.length; i++) {
        const ch = s[i];
        if (ch in map) {
            const top = stack.length > 0 ? stack.pop() : '#';
            if (top !== map[ch]) return false;
        } else {
            stack.push(ch);
        }
    }

    return stack.length === 0;
}

class MinStack {
    private stack: [number, number][] = [];

    push(val: number): void {
        const curMin = this.stack.length === 0 
            ? val 
            : Math.min(val, this.stack[this.stack.length - 1][1]);
        this.stack.push([val, curMin]);
    }

    pop(): void {
        this.stack.pop();
    }

    top(): number {
        return this.stack[this.stack.length - 1][0];
    }

    getMin(): number {
        return this.stack[this.stack.length - 1][1];
    }
}
import java.util.ArrayDeque;
import java.util.Deque;

public class StackProblems {
    public static boolean isValid(String s) {
        Deque<Character> stack = new ArrayDeque<>();

        for (char c : s.toCharArray()) {
            if (c == '(') stack.push(')');
            else if (c == '{') stack.push('}');
            else if (c == '[') stack.push(']');
            else if (stack.isEmpty() || stack.pop() != c) return false;
        }

        return stack.isEmpty();
    }
}

class MinStack {
    private Deque<Integer> stack = new ArrayDeque<>();
    private Deque<Integer> minStack = new ArrayDeque<>();

    public void push(int val) {
        stack.push(val);
        int currentMin = minStack.isEmpty() ? val : Math.min(val, minStack.peek());
        minStack.push(currentMin);
    }

    public void pop() {
        stack.pop();
        minStack.pop();
    }

    public int top() {
        return stack.peek();
    }

    public int getMin() {
        return minStack.peek();
    }
}
