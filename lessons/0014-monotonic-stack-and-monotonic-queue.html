Monotonic Stack & Monotonic Queue

Enforcing strict increasing or decreasing order. How to solve Next Greater Element, Daily Temperatures, and Largest Rectangle in Histogram in O(n) linear time.

The Monotonic Stack is one of Maddy's 9 Core Patterns and a hallmark of advanced interview mastery. Whenever a problem asks to find the nearest greater or smaller element for every item in an array, brute force scans forward costing $O(n^2)$. A monotonic stack solves it in a single pass of $O(n)$ time.

💡

Tied to Your Interview Mission

The core intuition: elements on the stack represent unresolved queries waiting for an answer. When a new element arrives that violates the monotonic order, it resolves the queries for all smaller elements waiting on the stack!

1. The Monotonic Invariant & The Linear O(n) Proof

In a monotonic decreasing stack, elements are ordered from largest at the bottom to smallest at the top: 

Current Stack: [75, 71, 69]  (indices of descending temperatures)
Incoming Item: 72

72 is GREATER than top item (69):
-> 72 is the Next Warmer Day for 69! Pop 69 and record answer.
72 is GREATER than next item (71):
-> 72 is the Next Warmer Day for 71! Pop 71 and record answer.
72 is NOT greater than 75:
-> Stop popping! Push 72 onto stack: [75, 72]

Why is this strictly $O(n)$? Every index is pushed onto the stack exactly once. When it is popped, it is gone forever. Across all $n$ loop iterations, the inner while loop can execute at most $n$ total pops → $O(n)$ amortized runtime.

Daily Temperatures

Key Learning Point: Store indices in a monotonic decreasing stack. When temps[i] > temps[stack.top()], pop index prev_idx and set ans[prev_idx] = i - prev_idx.

LeetCode 84 • Hard Grind 75 Week 8
Largest Rectangle in Histogram

Key Learning Point: Monotonic increasing stack. When a shorter bar arrives, previously taller bars can no longer extend rightward. Pop each taller bar and calculate rectangular area using its height and width bounded between current index and the bar remaining on stack.

LeetCode 239 • Hard Grind 75
Sliding Window Maximum

Key Learning Point: Monotonic decreasing deque of indices. Discard smaller elements from the tail of the deque before pushing incoming index; discard indices outside window from the head. Deque head always holds maximum in $O(1)$.

3. Pattern 1: Next Greater Element (Daily Temperatures)

def daily_temperatures(temperatures):
    ans = [0] * len(temperatures)
    stack = []  # stores indices of unresolved temperatures

    for i, temp in enumerate(temperatures):
        while stack and temp > temperatures[stack[-1]]:
            prev_idx = stack.pop()
            ans[prev_idx] = i - prev_idx
        stack.append(i)

    return ans

4. Pattern 2: Histogram Reach (Largest Rectangle in Histogram)

For each histogram bar of height $H$, what is the widest rectangle it can form? It extends left until hitting a shorter bar, and extends right until hitting a shorter bar.

By maintaining an increasing stack of indices, whenever we see a bar shorter than the top of the stack, we know the top bar's right boundary has terminated! 

Width formula when popping:
height = heights[popped_index]
width = i if not stack else (i - stack[-1] - 1)
area = height * width

5. Multi-Language Implementations: Daily Temperatures

Solving LeetCode 739 (Grind 75) in $O(n)$ time and $O(n)$ space across Python, TypeScript, and Java: 

def daily_temperatures(temperatures: list[int]) -> list[int]:
    """
    LeetCode 739 (Grind 75) - Monotonic Decreasing Stack.
    Time Complexity:  O(n) - each element pushed and popped at most once.
    Space Complexity: O(n) - stack stores at most n indices.
    """
    n = len(temperatures)
    ans = [0] * n
    stack = []  # stores indices

    for i, t in enumerate(temperatures):
        # Resolve all colder days waiting on stack
        while stack and t > temperatures[stack[-1]]:
            prev_idx = stack.pop()
            ans[prev_idx] = i - prev_idx
        stack.append(i)

    return ans
function dailyTemperatures(temperatures: number[]): number[] {
    // Time Complexity:  O(n)
    // Space Complexity: O(n)
    const n = temperatures.length;
    const ans = new Int32Array(n);
    const stack: number[] = [];

    for (let i = 0; i < n; i++) {
        const curTemp = temperatures[i];
        while (stack.length > 0 && curTemp > temperatures[stack[stack.length - 1]]) {
            const prevIdx = stack.pop()!;
            ans[prevIdx] = i - prevIdx;
        }
        stack.push(i);
    }

    return Array.from(ans);
}
import java.util.ArrayDeque;
import java.util.Deque;

public class DailyTemperatures {
    /**
     * LeetCode 739 (Grind 75) in O(n) time and O(n) space.
     */
    public static int[] dailyTemperatures(int[] temperatures) {
        int n = temperatures.length;
        int[] ans = new int[n];
        Deque<Integer> stack = new ArrayDeque<>();

        for (int i = 0; i < n; i++) {
            while (!stack.isEmpty() && temperatures[i] > temperatures[stack.peek()]) {
                int prevIdx = stack.pop();
                ans[prevIdx] = i - prevIdx;
            }
            stack.push(i);
        }

        return ans;
    }
}
