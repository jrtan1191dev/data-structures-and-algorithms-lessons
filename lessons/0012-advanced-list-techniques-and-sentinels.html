In production engineering and technical interviews, raw pointer manipulation easily leads to Null Pointer Exceptions (NPEs) or convoluted branching logic for boundary conditions (head or tail modifications). Sentinel Nodes and Composite Data Structures solve these issues with mathematical elegance.

💡

Tied to Your Interview Mission

The LRU Cache (LeetCode 146) is one of the most frequently asked interview problems in Big Tech history. It tests whether you can integrate two disparate data structures—a Doubly Linked List and a Hash Map—to achieve strictly O(1) time for both get and put operations.

1. The Dummy/Sentinel Node Superpower

When modifying a linked list where the head itself might change (merging lists, deleting elements, partitioning), writing special cases for head == null clutters code and invites bugs. 

Without Dummy Node:
if head == null: return new_node
if new_node.val < head.val:
    new_node.next = head
    head = new_node
# Cluttered edge-case logic!

With Dummy Node:
dummy = ListNode(-1)
dummy.next = head
curr = dummy
# All operations treat every node identically, including the original head!
return dummy.next

2. Grind 75 Questions & Key Learning Points

LeetCode 21 • Easy Grind 75 Week 1
Merge Two Sorted Lists

Key Learning Point: Create dummy = ListNode(0). Compare l1.val and l2.val, wire curr.next to the smaller node, and advance that list. Splice the non-empty remainder in $O(1)$ without a loop. Return dummy.next.

LeetCode 146 • Medium Grind 75 Week 4
LRU Cache

Key Learning Point: Map key -> Node in a Hash Map. Store nodes in a Doubly Linked List with dummy head and tail sentinels. Removing a node is $O(1)$ (`node.prev.next = node.next`). Inserting at head (MRU) is $O(1)$. Evicting least recently used (`tail.prev`) is $O(1)$.

LeetCode 143 • Medium Grind 75 Week 7
Reorder List

Key Learning Point: Integrates three foundational sub-skills: (1) Find list midpoint using slow/fast pointers, (2) Reverse second half in place, (3) Interleave alternating nodes from both halves in $O(1)$ space.

3. Three-Part Synthesis: Reorder List

Reordering $L_0 \to L_1 \to \dots \to L_{n-1} \to L_n$ into $L_0 \to L_n \to L_1 \to L_{n-1} \to \dots$ without extra memory: 

Original: [1] -> [2] -> [3] -> [4] -> [5] -> [6]

Step 1: Fast/slow pointers find midpoint:
First half:  [1] -> [2] -> [3] -> null
Second half: [4] -> [5] -> [6] -> null

Step 2: Reverse second half in place:
Reversed second: [6] -> [5] -> [4] -> null

Step 3: Interleave pointers p1 and p2:
Result: [1] -> [6] -> [2] -> [5] -> [3] -> [4] -> null

4. System Design Classic: The LRU Cache

[Dummy Head] <-> [Node Key: 2] <-> [Node Key: 1] <-> [Dummy Tail]
      ^                                                     ^
 (Most Recently Used)                              (Least Recently Used)

HashMap:
{
  1: 0x4000 (Pointer to Node 1),
  2: 0x2000 (Pointer to Node 2)
}

Operations:
- get(key): Lookup pointer in map in O(1). Remove node from list and insert at Head.
- put(key, val): If exists, update & move to Head. If capacity exceeded, evict tail.prev!

5. Multi-Language Implementations: Merge Two Sorted Lists

Solving LeetCode 21 (Grind 75) in $O(n + m)$ time and $O(1)$ space across Python, TypeScript, and Java: 

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

def merge_two_lists(list1: ListNode | None, list2: ListNode | None) -> ListNode | None:
    """
    LeetCode 21 (Grind 75) - Iterative with Sentinel Dummy Node.
    Time Complexity:  O(n + m) - single pass through both lists.
    Space Complexity: O(1) - in-place pointer adjustments.
    """
    dummy = ListNode(-1)
    curr = dummy

    while list1 and list2:
        if list1.val <= list2.val:
            curr.next = list1
            list1 = list1.next
        else:
            curr.next = list2
            list2 = list2.next
        curr = curr.next

    # Splice remaining non-empty tail in O(1)
    curr.next = list1 if list1 else list2

    return dummy.next
class ListNode {
    val: number;
    next: ListNode | null;
    constructor(val?: number, next?: ListNode | null) {
        this.val = val === undefined ? 0 : val;
        this.next = next === undefined ? null : next;
    }
}

function mergeTwoLists(list1: ListNode | null, list2: ListNode | null): ListNode | null {
    // Time Complexity:  O(n + m)
    // Space Complexity: O(1)
    const dummy = new ListNode(-1);
    let curr = dummy;

    while (list1 !== null && list2 !== null) {
        if (list1.val <= list2.val) {
            curr.next = list1;
            list1 = list1.next;
        } else {
            curr.next = list2;
            list2 = list2.next;
        }
        curr = curr.next;
    }

    curr.next = list1 !== null ? list1 : list2;
    return dummy.next;
}
public class MergeLists {
    /**
     * LeetCode 21 (Grind 75) in O(n + m) time and O(1) space.
     */
    public static ListNode mergeTwoLists(ListNode list1, ListNode list2) {
        ListNode dummy = new ListNode(-1);
        ListNode curr = dummy;

        while (list1 != null && list2 != null) {
            if (list1.val <= list2.val) {
                curr.next = list1;
                list1 = list1.next;
            } else {
                curr.next = list2;
                list2 = list2.next;
            }
            curr = curr.next;
        }

        curr.next = (list1 != null) ? list1 : list2;
        return dummy.next;
    }
}
