1D Dynamic Programming: Memoization vs Tabulation

Overlapping subproblems, top-down recursion stack frames vs bottom-up linear table cache locality, and state compression to O(1) memory.

1. Memory & Architecture

Top-Down vs Bottom-Up in the Memory Hierarchy

Dynamic Programming (DP) solves complex problems by breaking them down into simpler overlapping subproblems that possess optimal substructure.

Dimension Top-Down (Memoization) Bottom-Up (Tabulation)
Execution Model Recursive calls descending from target $N \to 0$. Iterative for loop building up from base cases $0 \to N$.
Memory Footprint $O(N)$ call stack frames + $O(N)$ memo table. $O(N)$ flat array table in contiguous RAM (no call stack).
CPU Cache Locality Non-linear stack jumps; cache hit rate varies. Sequential array iteration; maximum hardware L1/L2 prefetching.
Space Reduction Difficult; all active frames must remain in memory. Trivial: if $dp[i]$ depends only on $dp[i-1]$ and $dp[i-2]$, compress to 2 variables ($O(1)$ RAM).

The State Transition Recurrence

In Coin Change (LC 322), each subproblem represents the minimum coins required to make exact change for amount $a$:

Mathematical Recurrence Formula
Base Case:
dp[0] = 0
dp[a] = +inf  (for all a > 0)

Transition:
dp[a] = min_{c in coins, c <= a} (dp[a - c] + 1)

Result:
dp[amount] if dp[amount] != +inf else -1

3. Trilingual Reference Implementations

LC 322: Coin Change ($O(A \cdot C)$ Time, $O(A)$ Space Tabulation)

Python 3: 1D Array Tabulation
from typing import List

def coinChange(coins: List[int], amount: int) -> int:
    # Initialize table with amount + 1 (representing infinity)
    dp = [amount + 1] * (amount + 1)
    dp[0] = 0

    for a in range(1, amount + 1):
        for c in coins:
            if a - c >= 0:
                dp[a] = min(dp[a], dp[a - c] + 1)

    return dp[amount] if dp[amount] <= amount else -1
TypeScript: Fast Typed Number Array Tabulation
function coinChange(coins: number[], amount: number): number {
  const dp = new Array(amount + 1).fill(amount + 1);
  dp[0] = 0;

  for (let a = 1; a <= amount; a++) {
    for (const c of coins) {
      if (a - c >= 0) {
        dp[a] = Math.min(dp[a], dp[a - c] + 1);
      }
    }
  }

  return dp[amount] > amount ? -1 : dp[amount];
}
Java 21: Primitive int[] Array Tabulation
import java.util.Arrays;

public class Solution {
    public int coinChange(int[] coins, int amount) {
        int[] dp = new int[amount + 1];
        Arrays.fill(dp, amount + 1);
        dp[0] = 0;

        for (int a = 1; a <= amount; a++) {
            for (int c : coins) {
                if (a - c >= 0) {
                    dp[a] = Math.min(dp[a], dp[a - c] + 1);
                }
            }
        }

        return dp[amount] > amount ? -1 : dp[amount];
    }
}
