Converging & Opposing Two Pointers

How two boundary indices moving inward collapse brute-force O(n²) pair comparisons into an elegant, single-pass O(n) scan.

The Two Pointers Pattern is the first and most fundamental technique in Maddy's 9 Core Patterns and the NeetCode roadmap. It transforms nested loops that test all pairs $(i, j)$ into a linear traversal by leveraging monotonic properties.

💡

Tied to Your Interview Mission

When an interviewer mentions a sorted array, an in-place array manipulation, or asks for pair sum finding with $O(1)$ extra memory, your immediate instinct must jump to Two Pointers. It achieves the optimal $O(n)$ time while beating hash map approaches by requiring $O(1)$ auxiliary space.

1. The Mental Model: Search Space Pruning

In an array of length n, there are $\frac{n(n-1)}{2}$ possible pairs. A brute-force algorithm tests every single pair using nested loops: 

for i in range(n):
    for j in range(i + 1, n):
        # O(n²) pair comparisons

Converging pointers place left = 0 at the beginning and right = n - 1 at the end. At each step, we compute a value. Depending on whether that value is too small, too large, or optimal, we advance exactly one pointer. 

Search Space Matrix (sorted array):
       right ->
      [2,   7,  11,  15]
left [ .    .    .    . ]
 |   [      .    .    . ]
 v   [           .    . ]
     [                . ]

By moving 'right' leftward, we discard an ENTIRE COLUMN of invalid pairs in O(1)!
By moving 'left' rightward, we discard an ENTIRE ROW of invalid pairs in O(1)!

Because each iteration moves at least one pointer closer to the other, the loop runs at most n times → strictly O(n) time with O(1) space.

2. Canonical Pattern: Two Sum II on Sorted Sequences

Given an array sorted in non-decreasing order, find two indices such that their sum equals target:

  • current_sum = nums[left] + nums[right]
  • If current_sum == target: We found our unique pair! Return [left, right].
  • If current_sum < target: The sum is too small. Because the array is sorted, nums[right] is already the maximum available element. Pairing it with any element to the left of left would yield an even smaller sum. Therefore, left cannot be part of any valid solution → left += 1.
  • If current_sum > target: The sum is too large. Pairing nums[left] with any element to the right would be even larger. Therefore, right cannot be part of any solution → right -= 1.

3. Greedy Elimination: Container With Most Water

Given n non-negative integers representing vertical lines, find two lines that together with the x-axis form a container holding the most water: 

Area = (right - left) * min(height[left], height[right])

We start with the widest possible base: left = 0, right = n - 1. To find a larger area with a narrower width, we must find a taller height. The current area is constrained entirely by the shorter of the two lines. Moving the pointer at the taller line cannot possibly increase the area (the width shrinks, and the limiting height remains at best equal).

Therefore, we greedily discard the shorter wall: 

if height[left] < height[right]:
    left += 1
else:
    right -= 1

4. Multi-Language Implementations

Optimal implementations of Two Sum II ($O(n)$ time, $O(1)$ space) across Python, TypeScript, and Java: 

def two_sum_sorted(numbers: list[int], target: int) -> list[int]:
    """
    Finds 1-indexed pair summing to target in non-decreasing array.
    Time Complexity:  O(n) - at most n pointer moves.
    Space Complexity: O(1) - auxiliary pointers only.
    """
    left = 0
    right = len(numbers) - 1

    while left < right:
        current_sum = numbers[left] + numbers[right]
        if current_sum == target:
            # Return 1-indexed result as per interview standard
            return [left + 1, right + 1]
        elif current_sum < target:
            left += 1  # Need a larger number
        else:
            right -= 1 # Need a smaller number

    return []
function twoSumSorted(numbers: number[], target: number): number[] {
    // Time Complexity:  O(n) single pass
    // Space Complexity: O(1) in-place
    let left = 0;
    let right = numbers.length - 1;

    while (left < right) {
        const currentSum = numbers[left] + numbers[right];
        if (currentSum === target) {
            return [left + 1, right + 1];
        } else if (currentSum < target) {
            left++;
        } else {
            right--;
        }
    }

    return [];
}
public class TwoPointers {
    /**
     * Two Sum II in O(n) time and O(1) auxiliary space.
     */
    public static int[] twoSumSorted(int[] numbers, int target) {
        int left = 0;
        int right = numbers.length - 1;

        while (left < right) {
            int currentSum = numbers[left] + numbers[right];
            if (currentSum == target) {
                return new int[] { left + 1, right + 1 };
            } else if (currentSum < target) {
                left++;
            } else {
                right--;
            }
        }

        return new int[0];
    }
}
