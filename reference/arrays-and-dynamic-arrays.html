Arrays & Dynamic Arrays Cheatsheet

Memory layouts, indexing arithmetic, operation costs, and language-specific dynamic resizing internals.

1. The Contiguous Memory Formula

Arrays are sequential, unbroken blocks of bytes in RAM. Because every element has a uniform byte size, the CPU computes any element's memory address instantly:

Direct Indexing Address Calculation

MemoryAddress(i) = BaseAddress + (i × SizeOfElement)
Because this is a single multiplication and addition, looking up arr[0] and arr[10,000,000] both take O(1) time. Zero search is performed.

2. Operations Complexity Table

Operation Time Complexity Space Complexity Why?
Access by Index (arr[i]) O(1) O(1) Direct memory offset computation
Update by Index (arr[i] = x) O(1) O(1) Overwrites value at exact memory location
Append at End (Dynamic Array) O(1) amortized O(1) amortized Appends to spare capacity; resizes only when full
Pop / Remove from End O(1) O(1) Simply decrements internal length tracker
Insert at Index k O(n - k) → O(n) O(1) Must shift all elements from index k to n-1 rightward
Delete at Index k O(n - k) → O(n) O(1) Must shift all elements from index k+1 to n-1 leftward
Prepend at Beginning O(n) O(1) Must shift every single item right by 1 index
Slice / Subarray (length k) O(k) O(k) Allocates a brand new array and copies k items

3. Dynamic Array Resizing Mechanisms

Fixed arrays cannot grow without overwriting adjacent RAM. Dynamic arrays solve this by maintaining two numbers: Length (elements used) and Capacity (total allocated slots in RAM).

  • When Capacity is Exceeded: The system allocates a new array with geometric capacity (typically 1.5× or 2×), copies all existing items over (an O(n) operation), and frees the old block.
  • Why Append is Amortized O(1): Doubling capacity ensures that an O(n) resize happens after n cheap O(1) operations. The total cost of inserting n items is roughly 2n steps, averaging out to ~2 operations per insertion.

4. Idiomatic Implementations

# Python lists are dynamic arrays (pointers to objects)
nums = [10, 20, 30]

nums.append(40)         # O(1) amortized
val = nums[2]           # O(1) random access
nums.pop()              # O(1) removes last element

# Costly operations:
nums.insert(0, 99)      # O(n) shifts all elements right
nums.pop(0)             # O(n) shifts all elements left
sub = nums[1:3]         # O(k) creates a brand new copy!
// TypeScript / JS Arrays are dynamic
const nums: number[] = [10, 20, 30];

nums.push(40);          // O(1) amortized append
const val = nums[2];    // O(1) random access
nums.pop();             // O(1) removes last element

// Costly operations:
nums.unshift(99);       // O(n) prepends and shifts right
nums.shift();           // O(n) removes first and shifts left
const sub = nums.slice(1, 3); // O(k) shallow copy of slice
// Java distinguishes fixed arrays (int[]) vs dynamic (ArrayList)
import java.util.ArrayList;

// Fixed array (cannot change length)
int[] fixed = new int[5]; // Allocated in contiguous RAM
fixed[0] = 10;            // O(1)

// Dynamic array
ArrayList<Integer> nums = new ArrayList<>();
nums.add(10);            // O(1) amortized
nums.add(20);
int val = nums.get(1);   // O(1)
nums.remove(nums.size() - 1); // O(1) removes last

// Costly operations:
nums.add(0, 99);         // O(n) shifts all elements
nums.remove(0);          // O(n) shifts all elements
