Linked Lists, Stacks & Monotonic Sequences Cheatsheet

Sentinel node patterns, in-place pointer reversal, ring buffer arithmetic, and monotonic stack/queue templates for linear-time extreme extraction.

1. Linked List Patterns & Pointer Invariants

Technique Pointer Mechanism Invariant / Key Rule Canonical Problem
Dummy (Sentinel) Node dummy = ListNode(0); dummy.next = head Eliminates conditional checks for empty lists or head node removals. Return dummy.next. Merge Two Sorted Lists (LC 21), Remove Nth Node (LC 19)
In-Place 3-Pointer Reversal prev = null; curr = head; next_temp Preserve curr.next before re-pointing backward: curr.next = prev. Reverse Linked List (LC 206), Palindrome Linked List (LC 234)
Fast & Slow Pointers slow = slow.next; fast = fast.next.next When fast reaches end, slow is exactly at the midpoint $\lfloor N/2 \rfloor$. Middle of the Linked List (LC 876), Reorder List (LC 143)
DLL + Hash Map Synergy Hash map points directly to doubly linked list nodes $O(1)$ key lookup via map; $O(1)$ node eviction and splice to MRU head via DLL pointers. LRU Cache (LC 146)

2. LIFO / FIFO & Circular Ring Buffer Arithmetic

Circular Array Ring Buffer Formula

Fixed-size arrays simulate FIFO queues without $O(N)$ element shifts by maintaining two modular pointers:
Enqueue: arr[tail] = x; tail = (tail + 1) % capacity; size++
Dequeue: val = arr[head]; head = (head + 1) % capacity; size--
Condition: Full when size == capacity; Empty when size == 0.

3. Monotonic Invariant Comparison

Structure Monotonic Property Eviction Condition Canonical Use Case
Monotonic Decreasing Stack Values strictly decrease from bottom to top Pop while curr > stack[-1] Next Greater Element (LC 739 Daily Temperatures)
Monotonic Increasing Stack Values strictly increase from bottom to top Pop while curr < stack[-1] Next Smaller Element, Largest Rectangle in Histogram (LC 84)
Monotonic Deque Indices strictly increasing; values strictly decreasing Pop back while curr ≥ deque[-1]; pop front if out of window Sliding Window Maximum (LC 239)

def reverse_list(head):
    prev, curr = None, head
    while curr:
        nxt = curr.next
        curr.next = prev
        prev = curr
        curr = nxt
    return prev

def daily_temperatures(temperatures: list[int]) -> list[int]:

// 1. In-Place Linked List Reversal
function reverseList(head: ListNode | null): ListNode | null {
  let prev: ListNode | null = null;
  let curr = head;
  while (curr !== null) {
    const nextTemp = curr.next;
    curr.next = prev;
    prev = curr;
    curr = nextTemp;
  }
  return prev;
}

// 2. Monotonic Stack: Next Greater Element (LC 739)
function dailyTemperatures(temperatures: number[]): number[] {
  const n = temperatures.length;
  const ans = new Array(n).fill(0);
  const stack: number[] = []; // Stores indices

  for (let i = 0; i < n; i++) {
    while (stack.length > 0 && temperatures[stack[stack.length - 1]] < temperatures[i]) {
      const prevIdx = stack.pop()!;
      ans[prevIdx] = i - prevIdx;
    }
    stack.push(i);
  }

  return ans;
}
// 1. In-Place Linked List Reversal
public ListNode reverseList(ListNode head) {
    ListNode prev = null;
    ListNode curr = head;
    while (curr != null) {
        ListNode nextTemp = curr.next;
        curr.next = prev;
        prev = curr;
        curr = nextTemp;
    }
    return prev;
}

// 2. Monotonic Stack: Next Greater Element (LC 739)
import java.util.ArrayDeque;

public int[] dailyTemperatures(int[] temperatures) {
    int n = temperatures.length;
    int[] ans = new int[n];
    ArrayDeque<Integer> stack = new ArrayDeque<>(); // Stores indices

    for (int i = 0; i < n; i++) {
        while (!stack.isEmpty() && temperatures[stack.peek()] < temperatures[i]) {
            int prevIdx = stack.pop();
            ans[prevIdx] = i - prevIdx;
        }
        stack.push(i);
    }

    return ans;
}
