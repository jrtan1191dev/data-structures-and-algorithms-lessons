Backtracking & State Pruning Cheatsheet

Canonical Choose → Explore → Un-choose execution template, combinatorial branching models, branch-and-bound pruning, and in-place grid mutation rollbacks.

1. The 3 Combinatorial Archetypes

Problem Class State Space Size Branching Loop Setup Duplicate Prevention Rule
Subsets (Powerset) $2^N$ leaves for i in range(start, n): Pass i + 1 forward to prevent visiting earlier elements.
Combinations (K items) $\binom{N}{K}$ leaves for i in range(start, n): Prune early if remaining elements cannot fill quota: n - i < k - len(path).
Permutations $N!$ leaves for i in range(0, n): Track used elements via boolean[] used mask or swap elements in-place.

2. The Choose → Explore → Un-choose Framework

Mutable Path Buffer Protocol

3. Pruning & Memory Optimizations

Optimization Strategy Implementation Complexity Benefit
Sorted Boundary Pruning Sort candidates ascendingly; if candidate > target, break immediately instead of continue. Prunes massive exponential subtrees in Combination Sum (LC 39).
Sibling Duplicate Elimination If nums[i] == nums[i-1] and i > start, continue. Prevents duplicate branches when input contains repeated values (LC 40, LC 90).
In-Place Grid Sentinel Masking Overwrite grid cell byte with '#' before exploring neighbors; restore original byte on return. Achieves $O(1)$ auxiliary space without allocating an $O(R \times C)$ visited boolean array (LC 79).

# Combination Sum with Sort Pruning (LC 39)
def combination_sum(candidates: list[int], target: int) -> list[list[int]]:
    candidates.sort() # Upfront sort is required for branch break
    results, path = [], []

    def backtrack(start: int, remain: int):
        if remain == 0:
            results.append(path[:])
            return

        for i in range(start, len(candidates)):
            x = candidates[i]
            if x > remain:
                break # Prunes all subsequent larger candidates

            path.append(x)
            backtrack(i, remain - x) # Reuse allowed: stay at index i
            path.pop()

    backtrack(0, target)
    return results
// Combination Sum with Sort Pruning (LC 39)
function combinationSum(candidates: number[], target: number): number[][] {
  candidates.sort((a, b) => a - b);
  const results: number[][] = [];
  const path: number[] = [];

  function backtrack(start: number, remain: number): void {
    if (remain === 0) {
      results.push([...path]);
      return;
    }

    for (let i = start; i < candidates.length; i++) {
      const x = candidates[i];
      if (x > remain) break; // Prunes all subsequent candidates

      path.push(x);
      backtrack(i, remain - x); // Reuse allowed
      path.pop();
    }
  }

  backtrack(0, target);
  return results;
}
// Combination Sum with Sort Pruning (LC 39)
import java.util.*;

public List<List<Integer>> combinationSum(int[] candidates, int target) {
    Arrays.sort(candidates);
    List<List<Integer>> results = new ArrayList<>();
    backtrack(candidates, target, 0, new ArrayList<>(), results);
    return results;
}

private void backtrack(int[] candidates, int remain, int start, List<Integer> path, List<List<Integer>> results) {
    if (remain == 0) {
        results.add(new ArrayList<>(path));
        return;
    }

    for (int i = start; i < candidates.length; i++) {
        if (candidates[i] > remain) {
            break; // Prunes all subsequent candidates
        }

        path.add(candidates[i]);
        backtrack(candidates, remain - candidates[i], i, path, results);
        path.remove(path.size() - 1);
    }
}
