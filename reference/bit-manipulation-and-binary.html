Bit Manipulation & Binary Operations Cheatsheet

Hardware ALU bitwise primitives, XOR self-cancellation rules, bitmask recipes, and binary arithmetic without arithmetic operators.

1. Universal Bitmasking Recipes

Operation Bitwise Expression Physical Mechanism
Test if $k$-th bit is set (n >> k) & 1 == 1 Shifts bit $k$ to the units position and masks all higher bits with 1.
Set $k$-th bit to 1 n | (1 << k) OR with a mask containing 1 exclusively at position $k$.
Clear $k$-th bit to 0 n & ~(1 << k) AND with inverted mask having 0 at position $k$ and 1s elsewhere.
Toggle $k$-th bit n ^ (1 << k) XOR flips bit $k$ (0 becomes 1; 1 becomes 0).
Clear lowest set bit n & (n - 1) Brian Kernighan's trick: resets rightmost 1-bit to 0 in 1 ALU cycle.
Extract lowest set bit n & (-n) Exploits two's complement inversion: isolates lowest 1-bit as a power of 2.
Test if power of 2 n > 0 and (n & (n - 1)) == 0 Powers of 2 have exactly one 1-bit in their binary representation.

2. Algebraic Identities & XOR Magic

The 4 Laws of XOR ($^$)

  1. Identity: x ^ 0 = x
  2. Self-Cancellation: x ^ x = 0
  3. Commutative: a ^ b = b ^ a
  4. Associative: a ^ (b ^ c) = (a ^ b) ^ c

Implication: XORing an entire sequence cancels out all elements appearing an even number of times, leaving odd occurrences in $O(N)$ time and $O(1)$ memory.

def hamming_weight(n: int) -> int:
    count = 0
    while n:
        n &= (n - 1) # Clears lowest set bit
        count += 1
    return count

# 2. Add Two Numbers Without '+' (LC 371)
def get_sum(a: int, b: int) -> int:
    mask = 0xFFFFFFFF
    while b & mask != 0:
        carry = (a & b) << 1
        a = (a ^ b)
        b = carry
    return a if b > 0 else (a & mask)

    count++;
  }
