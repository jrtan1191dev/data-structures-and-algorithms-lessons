Intervals & Scheduling Cheatsheet

Sorting preconditions, overlap consolidation rules, greedy interval scheduling algorithms, and concurrent meeting room allocations.

1. The Three Core Interval Archetypes

Archetype Sorting Key Core Invariant & Greedy Rule Canonical Problems
Interval Merging Sort by Start Time If curr.start ≤ prev.end, overlap exists: prev.end = max(prev.end, curr.end). Merge Intervals (LC 56), Insert Interval (LC 57)
Non-Overlapping Scheduling Sort by End Time Earliest deadline first: greedily select intervals finishing earliest to maximize future timeline. Non-overlapping Intervals (LC 435), Minimum Arrows (LC 452)
Concurrent Resource Tracking Sort by Start Time + Min-Heap of Ends Min-heap tracks active end times. If heap.peek() ≤ curr.start, reuse resource (pop); else allocate new. Meeting Rooms II (LC 253)

2. Overlap Evaluation Decision Protocol

Two Sorted Intervals: A = [A.start, A.end] and B = [B.start, B.end] (where A.start ≤ B.start)

  • Disjoint (No Overlap): B.start > A.end → Push A to output, set prev = B.
  • Overlap: B.start ≤ A.end → Merge: A.end = max(A.end, B.end).
  • Insertion into Pre-Sorted Sequence (LC 57):
    Phase 1: Add all intervals where end < newInterval.start.
    Phase 2: Merge all intervals where start ≤ newInterval.end by expanding newInterval.
    Phase 3: Add all remaining intervals. Time: $O(N)$.

def merge_intervals(intervals: list[list[int]]) -> list[list[int]]:
    intervals.sort(key=lambda x: x[0])
    merged = [intervals[0]]
    for start, end in intervals[1:]:
        if start <= merged[-1][1]:
            merged[-1][1] = max(merged[-1][1], end)
        else:
            merged.append([start, end])
    return merged

def erase_overlap_intervals(intervals: list[list[int]]) -> int:
    intervals.sort(key=lambda x: x[1]) # Sort by end time
    removals, last_end = 0, float('-inf')
    for start, end in intervals:
        if start >= last_end:
            last_end = end
        else:
            removals += 1
    return removals
// Template 1: Merge Intervals (LC 56)
function mergeIntervals(intervals: number[][]): number[][] {
  intervals.sort((a, b) => a[0] - b[0]);
  const merged: number[][] = [intervals[0]];
  for (let i = 1; i < intervals.length; i++) {
    const prev = merged[merged.length - 1];
    const curr = intervals[i];
    if (curr[0] <= prev[1]) {
      prev[1] = Math.max(prev[1], curr[1]);
    } else {
      merged.push(curr);
    }
  }
  return merged;
}

// Template 2: Non-Overlapping Elimination (LC 435)
function eraseOverlapIntervals(intervals: number[][]): number {
  intervals.sort((a, b) => a[1] - b[1]); // Sort by end time
  let removals = 0;
  let lastEnd = -Infinity;
  for (const [start, end] of intervals) {
    if (start >= lastEnd) {
      lastEnd = end;
    } else {
      removals++;
    }
  }
  return removals;
}

import java.util.*;

public int[][] mergeIntervals(int[][] intervals) {
    Arrays.sort(intervals, Comparator.comparingInt(a -> a[0]));
    List<int[]> merged = new ArrayList<>();
    merged.add(intervals[0]);

    for (int i = 1; i < intervals.length; i++) {
        int[] prev = merged.get(merged.size() - 1);
        int[] curr = intervals[i];
        if (curr[0] <= prev[1]) {
            prev[1] = Math.max(prev[1], curr[1]);
        } else {
            merged.add(curr);
        }
    }
    return merged.toArray(new int[merged.size()][]);
}

public int eraseOverlapIntervals(int[][] intervals) {
    Arrays.sort(intervals, Comparator.comparingInt(a -> a[1])); // Sort by end time
    int removals = 0;
    int lastEnd = Integer.MIN_VALUE;

    for (int[] interval : intervals) {
        if (interval[0] >= lastEnd) {
            lastEnd = interval[1];
        } else {
            removals++;
        }
    }
    return removals;
}
