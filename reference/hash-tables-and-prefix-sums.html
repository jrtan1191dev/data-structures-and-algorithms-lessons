1. Collision Resolution Strategies

Strategy Physical RAM Structure Load Factor Threshold (α) Cache Locality & Trade-offs
Separate Chaining (Java HashMap) Array of bucket pointers pointing to linked lists (or Red-Black trees if bin count ≥ 8) α ≥ 0.75 Poor spatial cache locality due to scattered node pointers, but handles clustering gracefully without infinite probe cycles.
Linear Probing (Python dict) Single flat array; collisions probe sequentially (hash + i) % capacity α ≥ 0.66 Superior hardware cache line utilization; prone to primary clustering when consecutive buckets fill up.
Robin Hood Hashing Open addressing with age displacement (rich gives to poor) α ≥ 0.85 – 0.90 Minimizes search variance by equalizing probe distances; achieves high density with minimal lookup latency.

2. Prefix Sum & Subarray Algebraic Identities

The Subarray Sum Identity

For any subarray nums[i...j], its sum is given by:
Sum(i...j) = Prefix[j] - Prefix[i - 1] (where Prefix[k] = Sum(nums[0...k]))

Finding Subarrays with Sum Equals K (LC 560):
Prefix[j] - Prefix[i] = K &implies; Prefix[i] = Prefix[j] - K
Store running prefix sums in a hash map: count_map[prefix_sum] += 1.
Mandatory Boundary Initialization: Always initialize count_map[0] = 1 to account for valid subarrays starting at index 0.

# Subarray Sum Equals K (LC 560)
from collections import defaultdict

def subarray_sum(nums: list[int], k: int) -> int:
    prefix_counts = defaultdict(int)
    prefix_counts[0] = 1 # Essential base case
    curr_sum = total_subarrays = 0

    for x in nums:
        curr_sum += x
        if (curr_sum - k) in prefix_counts:
            total_subarrays += prefix_counts[curr_sum - k]
        prefix_counts[curr_sum] += 1

    return total_subarrays

function subarraySum(nums: number[], k: number): number {
  const prefixCounts = new Map<number, number>();
  prefixCounts.set(0, 1); // Essential base case

  let currSum = 0;
  let totalSubarrays = 0;

  for (const x of nums) {
    currSum += x;
    const target = currSum - k;
    if (prefixCounts.has(target)) {
      totalSubarrays += prefixCounts.get(target)!;
    }
    prefixCounts.set(currSum, (prefixCounts.get(currSum) || 0) + 1);
  }

  return totalSubarrays;
}

import java.util.HashMap;

public int subarraySum(int[] nums, int k) {
    HashMap<Integer, Integer> prefixCounts = new HashMap<>();
    prefixCounts.put(0, 1); // Essential base case

    int currSum = 0;
    int totalSubarrays = 0;

    for (int x : nums) {
        currSum += x;
        if (prefixCounts.containsKey(currSum - k)) {
            totalSubarrays += prefixCounts.get(currSum - k);
        }
        prefixCounts.put(currSum, prefixCounts.getOrDefault(currSum, 0) + 1);
    }

    return totalSubarrays;
}
