Two Pointers & Sliding Window Cheatsheet

Canonical templates, boundary invariants, state contraction conditions, and common edge cases across sequence patterns.

1. The Four Sequence Archetypes

Pattern Archetype Pointer Motion Core Invariant Canonical Problems
Converging (Opposing) left → ← right Monotonic search space reduction; each step eliminates an entire row or column. Two Sum II (LC 167), 3Sum (LC 15), Container With Most Water (LC 11), Valid Palindrome (LC 125)
Fast & Slow (Tortoise & Hare) slow += 1, fast += 2 Pointer speed differential guarantees collision in circular topologies or finds exact midpoints. Linked List Cycle (LC 141), Find the Duplicate Number (LC 287), Middle of the Linked List (LC 876)
Fixed-Size Sliding Window right += 1, left = right - k + 1 Window length is invariant ($k$); state updates in $O(1)$ by adding entering and subtracting exiting elements. Maximum Average Subarray I (LC 643), Permutation in String (LC 567), Find All Anagrams (LC 438)
Dynamic-Size Sliding Window right += 1; shrink left while condition broken Maintain validity invariant; expand greedily, contract minimally to discover optimal boundary. Longest Substring Without Repeating Characters (LC 3), Minimum Window Substring (LC 76), Character Replacement (LC 424)

2. Boundary Conditions & Invariants Checklist

Pre-Flight Verification Before Coding

  • Loop Termination: Use left < right when examining distinct pairs (e.g. Two Sum II, Container With Most Water). Use left ≤ right only if single-element windows are valid.
  • Window Length Calculation: The number of elements in $[left, right]$ is always right - left + 1 (inclusive).
  • Duplicate Elimination: In 3Sum, skip identical consecutive elements: while left < right and nums[left] == nums[left + 1]: left += 1.
  • State Contraction: In dynamic windows, update hash table / counter state before incrementing left.

# Template 1: Converging Pointers (Two Sum II)
def two_sum_sorted(nums: list[int], target: int) -> list[int]:
    left, right = 0, len(nums) - 1
    while left < right:
        curr = nums[left] + nums[right]
        if curr == target:
            return [left + 1, right + 1]
        elif curr < target:
            left += 1
        else:
            right -= 1
    return []

def length_of_longest_substring(s: str) -> int:
    last_seen = {}
    max_len = left = 0
    for right, ch in enumerate(s):
        if ch in last_seen and last_seen[ch] >= left:
            left = last_seen[ch] + 1
        last_seen[ch] = right
        max_len = max(max_len, right - left + 1)
    return max_len
// Template 1: Converging Pointers (Two Sum II)
function twoSumSorted(nums: number[], target: number): number[] {
  let left = 0;
  let right = nums.length - 1;
  while (left < right) {
    const sum = nums[left] + nums[right];
    if (sum === target) return [left + 1, right + 1];
    if (sum < target) left++;
    else right--;
  }
  return [];
}

// Template 2: Dynamic Sliding Window (Longest Substring)
function lengthOfLongestSubstring(s: string): number {
  const lastSeen = new Map<string, number>();
  let maxLen = 0;
  let left = 0;
  for (let right = 0; right < s.length; right++) {
    const ch = s[right];
    if (lastSeen.has(ch) && lastSeen.get(ch)! >= left) {
      left = lastSeen.get(ch)! + 1;
    }
    lastSeen.set(ch, right);
    maxLen = Math.max(maxLen, right - left + 1);
  }
  return maxLen;
}

// Template 2: Dynamic Sliding Window (Longest Substring)
import java.util.HashMap;

public int lengthOfLongestSubstring(String s) {
    HashMap<Character, Integer> lastSeen = new HashMap<>();
    int maxLen = 0, left = 0;
    for (int right = 0; right < s.length(); right++) {
        char ch = s.charAt(right);
        if (lastSeen.containsKey(ch) && lastSeen.get(ch) >= left) {
            left = lastSeen.get(ch) + 1;
        }
        lastSeen.put(ch, right);
        maxLen = Math.max(maxLen, right - left + 1);
    }
    return maxLen;
}
