Dynamic Programming Decision Framework

Systematic 4-step derivation protocol, canonical recurrence archetypes, and memory compression techniques from O(M × N) down to O(1).

1. The 4-Step DP Formulation Protocol

First-Principles Derivation Blueprint

  1. Define State: State clearly in natural language what $dp[i]$ or $dp[i][j]$ represents (e.g. "minimum coins to form amount $i$" or "length of LCS in prefixes $s1[0\dots i-1]$ and $s2[0\dots j-1]$").
  2. Establish Recurrence: Express $dp[\text{current}]$ strictly as an optimal combination of preceding subproblems (e.g. $\min$, $\max$, or $\sum$).
  3. Set Base Cases: Initialize trivial boundaries ($dp[0] = 0$, unreachable states $= +\infty$, empty strings).
  4. Order & Compress: Verify that subproblems are computed in topological order. Check if preceding states can be evicted to compress memory.

2. The Five Core Recurrence Archetypes

Archetype State Definition Transition Equation Space Optimization
1D Linear Prefix $dp[i]$: Optimal value ending at or using up to index $i$ $dp[i] = \max(dp[i-1], dp[i-2] + \text{val}[i])$ $O(N) \to O(1)$ via 2 rolling scalar variables
Unbounded Knapsack $dp[a]$: Minimum cost / ways to make change for amount $a$ $dp[a] = \min_{c} (dp[a - c] + 1)$ (forward left-to-right scan) $O(A)$ single 1D array
0/1 Knapsack $dp[w]$: Boolean reachability / max value with capacity $w$ $dp[w] = dp[w] \lor dp[w - \text{weight}]$ (reverse right-to-left scan) $O(W)$ single 1D array iterated backwards
2D Coordinate Grid $dp[r][c]$: Paths / cost to reach cell $(r, c)$ $dp[r][c] = dp[r-1][c] + dp[r][c-1]$ $O(R \times C) \to O(C)$ single 1D row array
2D String Subsequence $dp[i][j]$: Alignment score for prefixes $s_1[0\dots i-1]$ and $s_2[0\dots j-1]$ If match: $dp[i-1][j-1] + 1$; else: $\max(dp[i-1][j], dp[i][j-1])$ $O(M \times N) \to O(\min(M, N))$ dual-row rolling buffer

3. Memory Hierarchy & Cache Efficiency

Approach RAM Footprint CPU Cache Utilization Stack Frame Risk
Top-Down (Memoization) $O(N)$ hash table + $O(N)$ call frames Moderate; scattered stack pointers High (StackOverflow on large $N$)
Bottom-Up Tabulation $O(N)$ or $O(M \times N)$ contiguous array High; sequential cache prefetching Zero (pure iterative loops)
Compressed Rolling State $O(1)$ variables or $O(N)$ row buffer Optimal; fits entirely in L1/L2 cache Zero

# 1. Linear O(1) Space (House Robber)
def rob(nums: list[int]) -> int:
    prev1 = prev2 = 0
    for x in nums:
        prev1, prev2 = max(prev1, prev2 + x), prev1
    return prev1

# 2. 0/1 Knapsack Reverse Traversal (Partition Equal Subset Sum)
def can_partition(nums: list[int]) -> bool:
    total = sum(nums)
    if total % 2 != 0: return False
    target = total // 2
    dp = [False] * (target + 1)
    dp[0] = True
    for x in nums:
        # Reverse scan prevents reusing x in the same iteration
        for w in range(target, x - 1, -1):
            dp[w] = dp[w] or dp[w - x]
    return dp[target]
// 1. Linear O(1) Space (House Robber)
function rob(nums: number[]): number {
  let prev1 = 0, prev2 = 0;
  for (const x of nums) {
    const temp = Math.max(prev1, prev2 + x);
    prev2 = prev1;
    prev1 = temp;
  }
  return prev1;
}

// 2. 0/1 Knapsack Reverse Traversal (Partition Equal Subset Sum)
function canPartition(nums: number[]): boolean {
  const total = nums.reduce((a, b) => a + b, 0);
  if (total % 2 !== 0) return false;
  const target = total / 2;
  const dp = new Uint8Array(target + 1);
  dp[0] = 1;
  for (const x of nums) {
    for (let w = target; w >= x; w--) {
      if (dp[w - x] === 1) dp[w] = 1;
    }
  }
  return dp[target] === 1;
}

public int rob(int[] nums) {

    for (int x : nums) {
        int temp = Math.max(prev1, prev2 + x);
        prev2 = prev1;
        prev1 = temp;
    }
    return prev1;
}

// 2. 0/1 Knapsack Reverse Traversal (Partition Equal Subset Sum)
public boolean canPartition(int[] nums) {
    int total = 0;
    for (int x : nums) total += x;
    if (total % 2 != 0) return false;
    int target = total / 2;

    boolean[] dp = new boolean[target + 1];
    dp[0] = true;
    for (int x : nums) {
        for (int w = target; w >= x; w--) {
            dp[w] = dp[w] || dp[w - x];
        }
    }
    return dp[target];
}
