Heaps & Top-K Patterns Cheatsheet

Complete binary tree array indexing, Floyd's O(N) heapify mechanics, bounded Top-K priority queues, and dual-heap continuous stream median architectures.

1. Array Indexing Invariants

Relationship Array Formula Operation Complexity
Parent Node parent(i) = floor((i - 1) / 2) Sift-Up (insertion) O(log N) comparisons
Left Child left(i) = 2 * i + 1 Sift-Down (extract-min) O(log N) comparisons
Right Child right(i) = 2 * i + 2 Sift-Down (extract-min) O(log N) comparisons
Floyd's Heapify Sift-down from index $\lfloor N/2 \rfloor - 1$ down to 0 Build Heap in-place O(N) (convergent geometric sum)

2. Bounded Top-K Selection Rule

The Inverse Heap Rule for Extremes

  • To find the $K$ Largest Elements: Use a MIN-HEAP capped at size $K$.
    Push elements into the min-heap. When size exceeds $K$, pop the root (the minimum of the top $K+1$ candidates). At termination, the heap holds the $K$ largest elements, and the root is the $K$-th largest.
    Time: O(N log K) • Space: O(K) (avoids full O(N log N) sorting).
  • To find the $K$ Smallest Elements: Use a MAX-HEAP capped at size $K$.

3. The Two-Heaps Dynamic Median Architecture

Component Heap Type Invariant Median Extraction
Lower Half (Small) Max-Heap Holds smallest $\lceil N/2 \rceil$ numbers If len(small) > len(large): small[0]
Else: (small[0] + large[0]) / 2.0
Upper Half (Large) Min-Heap Holds largest $\lfloor N/2 \rfloor$ numbers; $\max(\text{small}) \le \min(\text{large})$

# Bounded Min-Heap: Kth Largest Element (LC 215)
import heapq

def find_kth_largest(nums: list[int], k: int) -> int:
    min_heap = []
    for x in nums:
        heapq.heappush(min_heap, x)
        if len(min_heap) > k:
            heapq.heappop(min_heap) # Evicts smallest candidate
    return min_heap[0]
// Bounded Min-Heap: Kth Largest Element (LC 215)
class MinHeap {
  private data: number[] = [];

  push(val: number): void {
    this.data.push(val);
    let i = this.data.length - 1;
    while (i > 0) {
      const p = Math.floor((i - 1) / 2);
      if (this.data[i] < this.data[p]) {
        [this.data[i], this.data[p]] = [this.data[p], this.data[i]];
        i = p;
      } else break;
    }
  }

  pop(): number {
    const top = this.data[0];
    const bottom = this.data.pop()!;
    if (this.data.length > 0) {
      this.data[0] = bottom;
      let i = 0;
      while (2 * i + 1 < this.data.length) {
        let best = 2 * i + 1;
        const r = 2 * i + 2;
        if (r < this.data.length && this.data[r] < this.data[best]) best = r;
        if (this.data[best] < this.data[i]) {
          [this.data[i], this.data[best]] = [this.data[best], this.data[i]];
          i = best;
        } else break;
      }
    }
    return top;
  }

  peek(): number { return this.data[0]; }
  get size(): number { return this.data.length; }
}

function findKthLargest(nums: number[], k: number): number {
  const heap = new MinHeap();
  for (const x of nums) {
    heap.push(x);
    if (heap.size > k) heap.pop();
  }
  return heap.peek();
}
// Bounded Min-Heap: Kth Largest Element (LC 215)
import java.util.PriorityQueue;

public int findKthLargest(int[] nums, int k) {
    PriorityQueue<Integer> minHeap = new PriorityQueue<>(k);

    for (int x : nums) {
        minHeap.offer(x);
        if (minHeap.size() > k) {
            minHeap.poll(); // Evicts smallest candidate
        }
    }

    return minHeap.peek();
}
