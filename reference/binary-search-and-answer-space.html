Binary Search & Answer Space Cheatsheet

Overflow-proof midpoint calculation, the 2 canonical loop templates, rotated array partition logic, and monotonic answer-space reductions.

1. The Two Canonical Binary Search Templates

Template Type Loop Condition Left Update Right Update Termination & Use Case
Template 1: Exact Match left ≤ right left = mid + 1 right = mid - 1 Terminates when left > right. Returns mid on exact match, else -1.
Template 2: Boundary / Insertion (Bisect Left) left < right left = mid + 1 right = mid Terminates with left == right. Finds first element satisfying condition (First Bad Version LC 278).

2. Midpoint Arithmetic & Rotated Sorted Arrays

Preventing 32-Bit Signed Integer Overflow

In Java, C++, and fixed-width languages, naive addition (left + right) / 2 overflows if left + right > 2^31 - 1.
Canonical Safe Formulation: mid = left + ((right - left) / 2)

Rotated Sorted Array Decision Rule (LC 33)

In a circularly shifted sorted array with no duplicates, at least one half is always strictly sorted:

  • If nums[mid] ≥ nums[left]: Left half is sorted. If nums[left] ≤ target < nums[mid], search left (right = mid - 1); else search right (left = mid + 1).
  • Otherwise: Right half is sorted. If nums[mid] < target ≤ nums[right], search right (left = mid + 1); else search left (right = mid - 1).

3. Binary Search on Answer Space Framework

Step Objective Concrete Example (Koko Eating Bananas LC 875)
1. Define Monotonic Predicate $f(x) \to \{\text{False}, \dots, \text{False}, \text{True}, \dots, \text{True}\}$ $f(k) = \text{hours}(k) \le H$. If speed $k$ suffices, all $k' > k$ also suffice.
2. Identify Bounds Determine minimum possible and maximum possible values $[low, high]$ $low = 1$ (minimum speed); $high = \max(\text{piles})$ (eat whole pile in 1 hour).
3. Converge on Boundary Use Template 2 (left < right) to pinpoint minimum valid parameter If $f(mid)$ is True: right = mid (try smaller); else: left = mid + 1.

# Template: Search in Rotated Sorted Array (LC 33)
def search_rotated(nums: list[int], target: int) -> int:
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = left + ((right - left) // 2)
        if nums[mid] == target:
            return mid

        # Left half is sorted
        if nums[left] <= nums[mid]:
            if nums[left] <= target < nums[mid]:
                right = mid - 1
            else:
                left = mid + 1
        # Right half is sorted
        else:
            if nums[mid] < target <= nums[right]:
                left = mid + 1
            else:
                right = mid - 1
    return -1
// Template: Search in Rotated Sorted Array (LC 33)
function searchRotated(nums: number[], target: number): number {
  let left = 0;
  let right = nums.length - 1;

  while (left <= right) {
    const mid = left + Math.floor((right - left) / 2);
    if (nums[mid] === target) return mid;

    // Left half is sorted
    if (nums[left] <= nums[mid]) {
      if (nums[left] <= target && target < nums[mid]) {
        right = mid - 1;
      } else {
        left = mid + 1;
      }
    }
    // Right half is sorted
    else {
      if (nums[mid] < target && target <= nums[right]) {
        left = mid + 1;
      } else {
        right = mid - 1;
      }
    }
  }

  return -1;
}
