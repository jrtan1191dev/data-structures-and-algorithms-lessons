# Notes

## Learner Background & Profile
- **Primary Goal**: Excel in technical coding interviews (FAANG-tier standard), while building rock-solid foundations for high-performance production code and intuitive problem-solving.
- **Starting Level**: Total beginner to algorithmic analysis. Needs to start from scratch with Big-O notation, asymptotic analysis, and basic memory/data representation (arrays, objects/hash maps).
- **Target Languages**: Python, TypeScript, and Java. Always provide solutions, idioms, and complexity nuances across all three.
- **Pedagogical Strategy**:
  - Focus on pattern recognition (following Maddy's 9 core patterns and NeetCode roadmap) rather than brute-force memorization.
  - Employ Maddy Zhang's 4-step transition mindset (Constraint Budgeting -> State Naive Brute Force -> Isolate Redundant Waste -> Select Invariant & Pattern) to deconstruct unseen problems.
  - Apply Gayle McDowell's 5 Optimization Heuristics: BUD (Bottlenecks, Unnecessary, Duplicated work), DIY (Do It Yourself on paper), Simplify & Generalize, Base Case & Build, and Data Structure Brainstorm.
  - Embed George Pólya's 4th step ("Look Back & Generalize") after every problem to convert solutions into reusable mental schemas.
  - Utilize physical visual mental models across data structures: "Line of Sight / Shadow Casting" (Monotonic Stack), "VIP Bouncer with Capacity K" (Heaps), "Expanding Water Ripples" (BFS), "Spool of Thread in a Maze" (DFS), "Search Matrix Geometric Cuts" (Two Pointers).
  - Protect against the "tutorial trap" using the 30-minute deliberate practice rule (15-min solitary struggle with whiteboard diagrams, pattern-only hints, active reproduction from empty buffer).
  - Pair theoretical proofs (Abdul Bari) with practical interview habits (Tech Interview Handbook).
  - Tufte-style clean HTML lessons with high interactive retrieval practice (quizzes with balanced choices, immediate feedback).
  - Central `index.html` at repository root acts as the syllabus/course hub, optimized for GitHub Pages hosting (with `.nojekyll`).
