# Notes

## Learner Background & Profile
- **Primary Goal**: Excel in technical coding interviews (FAANG-tier standard), while building rock-solid foundations for high-performance production code and intuitive problem-solving.
- **Starting Level**: Total beginner to algorithmic analysis. Needs to start from scratch with Big-O notation, asymptotic analysis, and basic memory/data representation (arrays, objects/hash maps).
- **Target Languages**: Python, TypeScript, and Java. Always provide solutions, idioms, and complexity nuances across all three.
- **Pedagogical Strategy**:
  - Focus on pattern recognition (following Maddy's 9 core patterns and NeetCode roadmap) rather than brute-force memorization.
  - Pair theory (Abdul Bari) with practical interview habits (Tech Interview Handbook).
  - Tufte-style clean HTML lessons with high interactive retrieval practice (quizzes with balanced choices, immediate feedback).
  - Central `index.html` at repository root acts as the syllabus/course hub, optimized for GitHub Pages hosting (with `.nojekyll`).
